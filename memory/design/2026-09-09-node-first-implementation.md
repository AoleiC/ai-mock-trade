# 节点先手体系 · 实现蓝图（唯一权威版）

> 本文件是买入/卖出体系的**实现蓝图与证据台账**：每条规则同时满足「有数据（或明示观察级）+ 时序可操作（判定时点早于出手时点）」。与各分册冲突处以本文档为准。
>
> 核心哲学：**出手左侧化、阶段判定保持右侧、先手 = 尾盘操作**——在情绪节点（[短情]冰点修复、回暖确认期、[板块]主升启动）提前拿轻仓先手，不等强势确认后追涨；全市场状态是仓位阀门而非二元开关；高潮期（确认完成时脉冲已近尾段）禁一切新开仓。

## 一、术语粒度规范（强制）

所有情绪类词汇**必须带粒度前缀**，禁止裸用：

| 前缀 | 含义 | 判定数据源 |
|------|------|-----------|
| [短情] | 短线情绪级（全市场情绪分 / 状态机） | `sentiment_score` 收盘序列、`regime-state.json` |
| [板块] | 板块级（热点分类） | 板块榜（`zt_count` 排序）、板块日级统计 |
| [大盘] | 指数级——**不参与任何买卖判定**，仅日志描述 | — |

状态机状态显示标签（枚举值 `defense / ice_point / uptrend_ready / uptrend / oscillation`）：

| 枚举 | 标签 |
|------|------|
| `defense` | [短情]退潮期 |
| `ice_point` | [短情]冰点期 |
| `uptrend_ready` | [短情]回暖确认期 |
| `uptrend` | [短情]高潮期 |
| `oscillation` | [短情]退潮分歧期 |

"主升"一词只归[板块]使用（如"[板块]主升启动"）。

## 二、核心时序纪律（体系基石）

1. **先手 = 尾盘操作**。所有预判型（左侧）出手统一在 **T 日 14:30~14:55 判定并执行**。信号必须在 T 日 14:30 前可判定——这是先手资格的硬前提。
2. **回放口径对齐**：全部回放统计的 "T+1 收益" 以 T 日收盘价为基准 ≈ **T 日尾盘买入的真实收益**。数据结论只对「尾盘先手」有效；**T+1 开盘追买不在数据保护范围内**（高开损耗未测）。
3. **禁止追认**：T 日尾盘信号通过但未出手 → 次日不追认昨日信号，按次日自身信号重新判定。追认 = 把尾盘先手退化成次日追涨。
4. **盘中（非尾盘）出手仅两类例外**：冰点通道 A/A2 的当帧拉起博弈（其设计本意就是盘中左侧）；持仓的节点减仓（卖出侧不受限）。

## 三、买入矩阵（5 条通道）

| # | 节点 | 判定标准（时点 + 数据） | 出手时点 | 仓位 | 证据等级 |
|---|------|------------------------|---------|------|---------|
| 1 | **[短情]冰点修复转势**（通道 A/A2/B） | 冰点聚簇 2≤深度≤4（状态机预计算）；A 冰中当帧 / A2 拉起确认 / B 尾盘双温度不回落 | A/A2 盘中当帧；B 尾盘 14:30~14:55 | 试错档 | ⚠️ 温度口径 7/8；个股收益未回测 |
| 2 | **[短情]回暖确认期**（通道 C） | T-1 收盘 s≥55（状态机 `up_count`）；当日当帧仍 ≥55 且共振 | 早盘 9:36~11:00 / 午后水下低吸 / 尾盘 14:30~14:55，当日一次 | 试错档 | ⚠️ 温度口径 62.5%；板块 T+1 胜率 100%（n=6）；实战待积累 |
| 3 | **[板块]主升启动**（通道 D） | [板块]连续 ≥2 日居市场前三（**昨日榜** `get_top_hot_spots --date <昨日>`，**当日榜** `get_hot_spot_list --sort_by zt_count` 实时——`get_top_hot_spots` 当日盘中返回空不可用；T 日 14:30 判定）+ 非撤退方向 | **T 日尾盘 14:30~14:55** | 试错档；[短情]退潮/冰点日折半 | ✅ n=60：T+1 +1.32%/胜率 73%；连榜 86% vs 首日 67%（n=21/39） |
| 4 | **[板块]连强中红盘休整**（通道 D 变体） | [板块]连强 run 中，当日板块涨幅收窄至 0~1%（红盘休整、未翻绿，`get_hot_spot_list` 实时 `avg_zdf`）且仍居前三 | **T 日尾盘 14:30~14:55** | 试错→标准 | ⚠️ n=6：T+1 +2.43%/胜率 100%（方向性线索，观察级） |
| 5 | **[短情]高潮期持仓管理** | 连续 3 日 s≥55（状态机） | **禁一切新开仓**（含通道 1~4）；仅持仓管理：节点减仓最敏感日、只减不加 | 只减 | ✅ 高潮期胜率 67% vs 确认期 100%（n=9/6）；确认完成时脉冲已近尾段，追入 = 接均值回归 |

**通道 3 标的画像**：板块内六池来源个股、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且**未涨停**（回放收益是板块核心成分均值，涨停股 T+1 可实现性未验证——禁追已涨停核心股）、资金面硬条件与分时四信号不否决（通用层 §2.2 同强度）；过四层矩阵 ②③④ 与心法红线。

## 四、卖出侧（3 层）

| 层 | 触发 | 动作 | 证据 |
|----|------|------|------|
| 节点先手减仓 | [短情]阶段转弱（晨起状态机较昨日转弱）→ 当日浮盈持仓逢高减；高潮期内 `saw_peak_70` 且当帧 <55 → 先手减半仓 | 先手减仓 | 状态机出口为代码权威 |
| **[板块]连强终结** | 连强 run 中板块**翻绿**（T 日 14:30 以 `get_hot_spot_list` 实时 `avg_zdf` 判定 <0）**或**跌出市场前三 → **48 小时内兑现** | 逢高分批 | ⚠️ n=2：翻绿后 T+2 -1.15%；加速日 T+1 仍有惯性（+1.44%/100%，n=8）——不抢跑、不拖延 |
| 形态止损止盈 | 个股 -5% / 加速止盈四信号 / 时间止损 | 照旧（通用层 §三） | 既有体系 |

## 五、永久闸门（任何通道不豁免）

1. **当天情绪闸**：当帧 [短情] `偏保守/保守` + `alignment=退潮` 同时出现 → 当日禁一切新开仓
2. **红线闸**：单只 ≤30%、[板块]同方向 ≤50%、交易所监管名单禁买、`position_limit` 直接采用

## 六、仓位阶梯（通用层 §2.5 三档）

试错档（≤目标 1/2）→ 标准档 → 重仓档（确认期验证链 + 最保守买点 + 环境健康三重确认）。**重仓只可能发生在回暖确认期内**——高潮期禁新开仓与补足；环境转弱期间禁止一切加重（只减不加）。

## 七、体系边界（不做的交易）

| 禁止项 | 依据 |
|--------|------|
| 板块翻绿低吸（"分歧抄底"） | 翻绿是走坏信号非分歧：翻绿后 T+2 -1.15%/胜率 0%（n=2） |
| 板块级"分歧转一致"量化触发 | 板块级回封确认数据不存在，无可操作判别式——仅作描述性语言，不触发交易 |
| 首日进榜当日追买（Day 1 抢跑） | 首日胜率 67% < 连榜 86%——新冒头方向当日只记录，次日仍居前三按通道 D 参与 |
| T+1 开盘追买（追认昨日信号） | 时序纪律 §二.3；高开损耗未测，不在回放数据保护范围 |
| 高潮期新开仓 / 补足 | 确认完成时脉冲已近尾段（§三 #5） |
| 水上追高（午后水上 > +3%） | 通用层 §0.8 午后纪律 |

## 八、证据台账（回放窗口 2026-06-17~09-08，板块级干净窗口 07-30 后）

| 结论 | 数据 | 样本 | 局限 |
|------|------|------|------|
| 退潮/冰点日强势[板块] T+1 正期望 | +1.32% / 73% | n=60 | 板块均值 ≠ 可实现收益（涨停不可买） |
| [板块]连榜 2 日 vs 首日进榜 | 胜率 86% vs 67% | n=21/39 | 小样本 |
| [板块]连续强势 run vs [短情]连续 ≥55 run | 27 段 vs 5 段 | 60 日 | "主升"属[板块]粒度的存在性证据 |
| 高潮期 vs 确认期板块 T+1 | 67%（n=9）vs 100%（n=6） | 小 | 方向一致的双口径 |
| [板块]红盘休整 T+1 | +2.43% / 100% | n=6 | 观察级 |
| [板块]翻绿后 T+2 | -1.15% / 0% | n=2 | 方向性 |
| [板块]加速日 T+1 | +1.44% / 100% | n=8 | 惯性存在，T+2 衰减至 -0.07% |
| 单日[短情]强延续率 | 36%（8/22） | 60 日 | 反证追涨 |
| 冰点后 3 日内修复 | 7/8 | 60 日 | 温度口径 |

**口径声明**：全部 T+1 收益以 T 日收盘价为基准 = 尾盘先手口径（§二.2）。板块收益为 `avg_zdf`（核心成分均值）。历史盘中分时帧不存在，盘中级条款（A/A2/C 早盘）只能前向验证——**所有 ⚠️ 条款挂观察级，出手时 trade-log `reason` 前缀标注 `channel=X`（复盘汇总进当日 `daily-summary`），≥8 次后依 T+2 成立率审定去留**。
