# 战法四：退潮防守（`defense`，默认兜底）

> 适用阶段：防守状态（默认兜底）；**主升预备态行为同防守，且通道 C 确认期先手对两态同样适用**；冰点态簇深 <2（未成型）或 ≥5（长熊防御）亦按本分册执行。通用细则见 `memory/dynamic-strategy.md`。

## 一、允许

- 持仓止损止盈、加速止盈、撤退方向减仓、**节点先手减仓**（通用层 §3.0：A 阶段转弱晨起先手为数据支撑条，B/C 为观察级；浮盈持仓适用）（**风控不设时间窗**——卖出动作不受状态机限制）
- **通道 C 确认期先手**（防守 / 预备态唯一开仓通道，条件见 §二A）——通道定位是"升温节点提前参与博弈的约定"，不是普放开仓
- 记录观察：watchlist / emerging / 轮动台账照常写（只记录不出手，为轮动预判与状态切换积累数据）

## 二、禁止

- **一切新开仓，唯一例外为通道 C（§二A）**——冰点三通道（A/A2/B）仍不开放，它们是冰点态专属且需 `next_day_channel_open`；非确认期（`up_count==0` 且非预备态）的防守日当帧情绪再好也不开仓（等一日让其成为确认日，成本低；防线价值见 §三数据锚点）
- 补足笔 / 加仓视同新开仓，同样禁止（通道 C 试错笔成交后当日不再补足；已有持仓的止损止盈不受影响）

## 二A、通道 C：确认期先手（防守 / 预备态唯一开仓通道）

**资格（满足其一即处于确认期，防御触发日不开通道）**：

1. 生效状态 = 防守 且 `up_count == 1`：昨日收盘 s ≥ 55 且为连续第 1 日（双日确认中的第 1 个确认日）
2. 生效状态 = 主升预备（`current_state == "uptrend_ready"`，晨起 `up_count >= 2`）：第 3 日确认日前夜——博弈次日主升放行

> 设计动机：右侧确认系统"等强势才买"在 T+1 下天然成本高——全量放行日（第 4 日）龙头常已 2 板、买得进的价格没了。确认期先手用轻仓 + 节点认证换时间上的左侧。数据：双日确认后第 3 日延续率 5/8（62.5%）> 单日确认次日 36% > 无确认追当帧 0/3——**出手可以左侧，阶段判定保持右侧**（确认期资格本身是收盘定格证据，不用当帧猜阶段）。

**窗口（全天可出手，时段分级认证，当日合计只出手一次；试错笔规模锚 = 通用层 §2.5 试错档 ≤ 目标 1/2，升级路径见 §2.5 先手仓升级）**：

| 时段 | 认证 | 标的约束 |
|------|------|----------|
| 早盘段 9:36~11:00 | 当帧 `sentiment_score` ≥ 55 **且** `alignment == 共振` **且** 方向验证（见下） | 标准画像（见出手条件 4） |
| 午后段 11:00~14:30 | 同早盘段认证 | **只做水下低吸**（`zdf` -5%~0% 或分时回踩关键支撑企稳，通用层 §0.6；水上 > +3% 不追——对齐通用层 §0.8 午后纪律） |
| 尾盘段 14:30~14:55 | 14:30 后最近两帧短线温度均 ≥ 昨收短线温度 **且** 当帧大盘温度 ≥ 昨收大盘温度（昨收取 `regime-state.json` 的 `history` 末条）**且** `alignment == 共振` | 标准画像 |

**方向验证（各时段共用）**：方向 ∈ 当帧 `attack_directions` / `attack_sectors`，且该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_daily_stats` 当日行，与通道 A2 同款要件）。

**标的画像（标准）**：六池来源、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且日内最高涨幅 ≤7%（`y1` 极值口径）、资金面硬条件与分时四信号不否决（通用层 §2.2 同强度）；过四层矩阵 ②③④ 与心法红线。

**风控（试错笔专属）**：确认失败（当日收盘 s < 55）或次日开盘走弱 → **次日无条件离场，不等止损位**；常规止损 / 时间止损照常生效且优先级更高。隔夜黑天鹅同冰点通道处置（止损照常，试错仓封顶损失）。

**证据分级（观察级条款）**：通道 C 是未经历史回放验证的前向假设（当帧历史数据不存在）。每次出手落库 `regime_track` 标 `channel=C`（确认日 / 预备日区分标注），**累计 ≥8 次后由用户依 T+2 验证成立率审定去留**；数据不足期间定位观察级，与通道 A/A2 同等待遇。

## 三、数据锚点

- 56 日重放中防守 29 日（52%）+ 预备 4 日 + 冰点未成型 / 长熊关闭日，合计完全禁新开仓 41 日（73%)；错失代价由防守态错失成本指标前向度量（设计文档 §8.3）
- 当前实例：09-02（s=20）/ 09-03（s=20 收盘定格，双冰成型转冰点态）
- 通道 C 设立依据（2026-09-08 用户审定）：60 日样本"昨 s≥55 → 今仍 ≥55"8/22（36%）、"双日确认 → 第 3 日"5/8（62.5%）、低位跳变次日 0/3——**出手左侧化（确认期先手）、阶段判定保持右侧（收盘序列）**为数据支持的最大自由度；"全天可买看当日情绪"不采纳（当帧强延续率 36%，防线拆除即退化追涨杀跌）；另 8 例"连降 2 日后第 3 日"中 7 例第 3 日已入冰位（冰点三通道管辖），中位降温仅 1 例样本不足、不另开通道
