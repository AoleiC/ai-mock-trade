# 战法四：[短情]退潮期防守（`defense`，默认兜底）

> 适用阶段：[短情]退潮期（默认兜底）；**[短情]回暖确认期行为同退潮期，通道 C 确认期先手与通道 D 对两态同样适用**；冰点期簇深 <2（未成型）或 ≥5（长熊防御）亦按本分册执行（通道 D 在冰点期同样适用）。**[短情]高潮期禁一切新开仓（含 C/D），见 `20-main-uptrend.md`**。通用细则见 `memory/dynamic-strategy.md`；体系总纲与证据台账见 `memory/design/2026-09-09-node-first-implementation.md`。

## 一、允许

- 持仓止损止盈、加速止盈、撤退方向减仓、**节点先手减仓**（通用层 §3.0：A 阶段转弱晨起先手为数据支撑条，B/C 为观察级；浮盈持仓适用）（**风控不设时间窗**——卖出动作不受状态机限制）
- **通道 C 确认期先手**（[短情]粒度转势试错，条件见 §二A）——通道定位是"升温节点提前参与博弈的约定"，不是普放开仓
- **通道 D [板块]主升启动尾盘先手**（[板块]粒度，条件见 §二C）——绕过[短情]状态标签的板块级日常通道
- 记录观察：watchlist / emerging / 轮动台账照常写（只记录不出手，为轮动预判与状态切换积累数据）

## 二、禁止

- **一切新开仓，例外仅通道 C（§二A）与通道 D（§二C）**——冰点三通道（A/A2/B）仍不开放，它们是冰点态专属且需 `next_day_channel_open`；非确认期（`up_count==0` 且非预备态）且无通道 D 资格的退潮期交易日当帧情绪再好也不开仓（等一日让其成为确认日，成本低；防线价值见 §三数据锚点）
- 补足笔 / 加仓视同新开仓，同样禁止（通道 C/D 试错笔成交后当日不再补足；已有持仓的止损止盈不受影响）

## 二A、通道 C：确认期先手（防守 / 预备态唯一开仓通道）

**资格（满足其一即处于确认期，防御触发日不开通道）**：

1. 生效状态 = 退潮期 且 `up_count == 1`：昨日收盘 s ≥ 55 且为连续第 1 日（双日确认中的第 1 个确认日）
2. 生效状态 = 回暖确认期（`current_state == "uptrend_ready"`，晨起 `up_count >= 2`）：第 3 日确认日前夜——博弈次日转入高潮期（**买在确认期、在高潮期兑现**：转入后禁新开仓，由 `20` 分册节点减仓管理退出）

> 设计动机：确认期先手用轻仓 + 节点认证换时间上的左侧。数据：双日确认后第 3 日延续率 5/8（62.5%）> 单日确认次日 36% > 无确认追当帧 0/3——**出手可以左侧，阶段判定保持右侧**（确认期资格本身是收盘定格证据，不用当帧猜阶段）。确认期板块 T+1 胜率 100%（n=6）是全体系最甜窗口；转入高潮期后胜率塌陷至 67%——确认期先手 + 高潮期禁买的组合正是"买在转势、卖在高潮"的实现。

**窗口（全天可出手，时段分级认证，当日合计只出手一次；试错笔规模锚 = 通用层 §2.5 试错档 ≤ 目标 1/2，升级路径见 §2.5 先手仓升级）**：

| 时段 | 认证 | 标的约束 |
|------|------|----------|
| 早盘段 9:36~11:00 | 当帧 `sentiment_score` ≥ 55 **且** `alignment == 共振` **且** 方向验证（见下） | 标准画像（见出手条件 4） |
| 午后段 11:00~14:30 | 同早盘段认证 | **只做水下低吸**（`zdf` -5%~0% 或分时回踩关键支撑企稳，通用层 §0.6；水上 > +3% 不追——对齐通用层 §0.8 午后纪律） |
| 尾盘段 14:30~14:55 | 14:30 后最近两帧短线温度均 ≥ 昨收短线温度 **且** 当帧大盘温度 ≥ 昨收大盘温度（昨收 s/d **逐字取 `regime-state.json` 的 `history` 末条数值，禁止凭记忆 / 推测写昨收值**）**且** `alignment == 共振` | 标准画像 |

**方向验证（各时段共用）**：方向 ∈ 当帧 `attack_directions` / `attack_sectors`，且该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_daily_stats` 当日行，与通道 A2 同款要件）。

**标的画像（标准）**：六池来源、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且日内最高涨幅 ≤7%（`y1` 极值口径）、资金面硬条件与分时四信号不否决（通用层 §2.2 同强度）；过四层矩阵 ②③④ 与心法红线。

**风控（试错笔专属）**：确认失败（当日收盘 s < 55）或次日开盘走弱 → **次日无条件离场，不等止损位**；常规止损 / 时间止损照常生效且优先级更高。隔夜黑天鹅同冰点通道处置（止损照常，试错仓封顶损失）。

**证据分级（观察级条款）**：通道 C 是未经历史回放验证的前向假设（当帧历史数据不存在）。每次出手的 trade-log `reason` 前缀标注 `channel=C`（确认日 / 预备日区分标注，复盘汇总进当日 `daily-summary`），**累计 ≥8 次后由用户依 T+2 验证成立率审定去留**；数据不足期间定位观察级，与通道 A/A2 同等待遇。

## 二C、通道 D：[板块]主升启动尾盘先手（[板块]粒度日常通道）

> 设立依据（回放数据，`memory/design/2026-09-09-node-first-implementation.md` §八）：[短情]连续 ≥55 的 run 60 日内仅 5 段，而[板块]连续居前三 27 段——持续性行情的常态在板块粒度；且退潮期/冰点日强势[板块] T+1 +1.32%/胜率 73%（n=60）与 gate 开放日无显著差异——"[短情]不好则[板块]不可持续"被证伪。通道 D 是绕过[短情]状态标签的**板块级日常通道**。

**资格（全部满足）**：

1. 生效状态 ∈ {退潮期, 冰点期, 回暖确认期}（**高潮期不适用**——高潮期禁一切新开仓）
2. **[板块]主升启动信号**：该板块已连续 ≥2 个交易日居市场热度前三（zt_count 排序；**昨日榜**取 `get_top_hot_spots --date <昨日> --limit 3`，**当日榜**取 `get_hot_spot_list --sort_by zt_count --limit 3` 实时榜——注意 `get_top_hot_spots` 的当日行盘中返回空、不可用于当日判定；并列涨停数按服务端排序取前 3，与回放统计同口径；当日榜在 T 日 14:30 判定，尾盘榜基本定型）
   **数据自愈纪律（与状态机自愈同哲学）**：连榜判定**只依赖上述行情接口**（服务端历史数据，任何时刻可当场重建），**禁止依赖昨日 `daily-summary` / `rotation_ledger` 是否存在**——昨日复盘缺失与否不影响通道 D 资格判定；接口调用失败才按 §0.8.1 数据限制处理（无法判定 → 不参与），复盘产物缺失不是"数据缺位"
3. 该板块 ∉ 当帧撤退方向（`retreat_directions` / `retreat_sectors`）
4. 当天情绪闸不拦（`sentiment_label ∈ {保守, 偏保守}` 且 `alignment == 退潮` → 当日禁一切新开仓，通道 D 不豁免）

**窗口与出手时点（时序纪律）**：

- **仅尾盘段 14:30~14:55 判定并出手**——先手 = 尾盘操作（设计文档 §二.1）；回放口径（T+1 收益以 T 日收盘价为基准）只保护尾盘买入，T+1 开盘追买不在数据保护范围
- **禁止追认**：T 日尾盘信号通过但未出手 → 次日不追认昨日信号，按次日自身信号重新判定
- 当日合计只出手一次（与通道 C 共享当日出手次数）

**变体（红盘休整加码，观察级）**：连强 run 中该板块当日涨幅收窄至 0~1%（红盘但休整、未翻绿）且仍居前三（当日实时 `avg_zdf` 取 `get_hot_spot_list`）→ 视为更甜的参与位（T+1 +2.43%/100%，n=6，方向性线索）；**翻绿不是分歧、是走坏信号——禁止翻绿低吸**（翻绿后 T+2 -1.15%/0%，n=2）。

**标的画像**：板块内六池来源个股、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且**未涨停**（回放收益是板块核心成分均值，涨停股 T+1 可实现性未验证——禁追已涨停核心股）、资金面硬条件与分时四信号不否决（通用层 §2.2 同强度）；过四层矩阵 ②③④ 与心法红线。

**仓位**：试错档（≤ 目标 1/2，通用层 §2.5）；[短情]退潮期/冰点日**仓位上限折半**，回暖确认期足额。

**风控**：[板块]连强终结信号（翻绿 / 跌出前三，T 日 14:30 以 `get_hot_spot_list` 实时榜可判定）→ **48 小时内兑现**（逢高分批，不抢跑——加速日 T+1 仍有惯性 n=8 +1.44%/100%，不拖延——翻绿后 T+2 转负）；常规止损 / 时间止损照常且优先级更高。

**证据分级**：资格条款为回放数据级（✅ n=60/21/39）；红盘休整变体为观察级（⚠️ n=6）；每次出手的 trade-log `reason` 前缀标注 `channel=D`（标注是否红盘休整变体，复盘汇总进当日 `daily-summary`），**累计 ≥8 次后依 T+2 成立率审定去留**。

## 三、数据锚点

- 56 日重放中退潮期 29 日（52%）+ 回暖确认期 4 日 + 冰点未成型 / 长熊关闭日；通道 D 落地后禁开仓口径为"无[板块]连强信号的交易日"（板块连强 27 段的存在性使纯禁仓日大幅减少）
- 当前实例：09-02（s=20）/ 09-03（s=20 收盘定格，双冰成型转冰点态）
- 通道 C 数据锚点：60 日样本"昨 s≥55 → 今仍 ≥55"8/22（36%）、"双日确认 → 第 3 日"5/8（62.5%）、低位跳变次日 0/3——**出手左侧化（确认期先手）、阶段判定保持右侧（收盘序列）**为数据支持的最大自由度；"全天可买看当日情绪"不采纳（当帧强延续率 36%，防线拆除即退化追涨杀跌）；另 8 例"连降 2 日后第 3 日"中 7 例第 3 日已入冰位（冰点三通道管辖），中位降温仅 1 例样本不足、不另开通道
- 通道 D 数据锚点：退潮/冰点日强势[板块] T+1 +1.32%/73%（n=60）；连榜 ≥2 日胜率 86% vs 首日 67%（n=21/39）；红盘休整 +2.43%/100%（n=6）；翻绿后 T+2 -1.15%（n=2）；加速日 T+1 惯性 +1.44%/100%（n=8）——完整台账见 `memory/design/2026-09-09-node-first-implementation.md` §八
