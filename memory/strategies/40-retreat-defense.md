# 战法四：[短情]退潮期防守（`defense`，默认兜底）

> 适用阶段：[短情]退潮期（默认兜底，**禁一切新开仓、无例外——市场节点一票否决，节点不对题材再强不买，心法 §三**）；升温节点（回暖确认期、升温第 1 日及高潮第 1 日）的先手通道 C / D 见本分册 §二A / §二C；冰点期分层试错通道见 `10-ice-point.md`（通道开放日通道 D 亦适用；单冰日不操作）；降温期见 `30` 分册；**[短情]高潮期第 2 日起禁一切新开仓（含 C/D），见 `20-main-uptrend.md`**。通用细则见 `memory/dynamic-strategy.md`。

## 一、允许

- 持仓止损止盈、加速止盈、撤退方向减仓、**节点先手减仓**（通用层 §3.0：A 阶段转弱晨起先手为数据支撑条，B/C 为观察级；浮盈持仓适用）（**风控不设时间窗**——卖出动作不受状态机限制）
- **通道 C 升温节点先手**（升温第 1 日 / 回暖确认期 / 高潮第 1 日，条件见 §二A）——升温节点内的市场级试错通道
- **通道 D 板块连强尾盘先手**（**仅升温节点（含高潮第 1 日）、冰点通道开放日与冰点反弹延续日**，条件见 §二C）——节点许可窗口内的板块级机会通道；**退潮期（非升温第 1 日、非反弹延续日）/ 降温期 / 高潮第 2 日起一律不适用**
- **冰点反弹延续日通道**（`next_day_rebound_channel_open == true`，挂起第 1 日）：A2 / D 延续开放（`10-ice-point.md` §一），该日豁免退潮禁令——反弹余韵属冰点博弈延续，非真退潮
- **通道 E V 型修复尾盘先手**（`next_day_v_repair_ready == true`，冰点簇挂起第 2 日，条件见 §二E）——"冰点-大涨-回调-修复"四步形态修复日的尾盘小仓预判通道；仅 14:30~14:55 窗口、当帧大盘主源认证、小仓兜底
- 记录观察：emerging 方向在盯盘总结正文中照常记录（板块名 + 排名，只记录不出手，为状态切换与通道 D 资格积累数据，总纲 §7.2）

## 二、禁止

- **退潮期一切新开仓，无例外**——市场节点一票否决（心法 §三）：节点不对，题材再强、板块再热都不买；冰点分层通道（A/A2/B）是冰点节点专属，退潮期不适用（资格见 `10-ice-point.md`）；**升温第 1 日不计入退潮禁令**——昨日收盘 s 已站上 55，温度事实属升温节点（§二A 资格 1，字段 `up_count == 1`）；**冰点反弹延续日（`next_day_rebound_channel_open == true`，挂起第 1 日）同样豁免**——从冰点爬出来的反弹余韵是冰点博弈的延续、非真退潮，A2/D 照常开放（`10-ice-point.md` §一）；**V 型修复日（`next_day_v_repair_ready == true`，冰点簇挂起第 2 日）同样豁免**——仅通道 E 尾盘小仓先手（§二E），非全天开放
- 补足笔 / 加仓视同新开仓，同样禁止（退潮期本就禁一切新开仓）；已有持仓的止损止盈不受影响

## 二A、通道 C：升温节点先手（升温第 1 日 / 回暖确认期唯一开仓通道）

**资格（满足其一即处于升温节点，防御触发日不开通道；`up_count` 从 `read_regime_state` 返回值读取）**：

1. **升温第 1 日**：晨起 `current_state == "defense"` 且 `up_count == 1`——昨日收盘 s ≥ 55 第 1 日。温度事实已进入升温区，状态机双日确认只是防抖标签，**按升温节点处理，不计入退潮禁令**
2. **回暖确认期**：`current_state == "uptrend_ready"`（晨起 `up_count >= 2`）：第 3 日确认日前夜——博弈次日转入高潮期（**买在升温节点、在高潮期兑现**：转入后第 2 日起禁新开仓，由 `20` 分册节点减仓管理退出）
3. **高潮第 1 日（升温惯性延续日）**：`current_state == "uptrend"` 且 `uptrend_first_day == true`（读取时派生：状态恰在最近已完成交易日转入）——转入高潮的背书要求当日大盘标签 ∈ {修复, 升温}，故第 1 日必然是"大盘还在升温"的双强惯性日，通道 C/D 视同升温节点照常开放；**高潮第 2 日起背书可能消失（大盘转降温）、均值回归临近，全禁**（`20` 分册）。观察级：高潮期追入 T+1 胜率 67%（n=9）未按日切分，第 1 日子样本不足，按通道 C 同款累计 ≥8 次后审定

> 设计动机：升温节点先手用轻仓 + 节点认证换时间上的左侧。数据：双日确认后第 3 日延续率 5/8（62.5%）> 单日确认次日 36% > 无确认追当帧 0/3——**出手可以左侧，阶段判定保持右侧**（节点资格本身是收盘定格证据，不用当帧猜阶段）。升温期板块 T+1 胜率 100%（n=6）是全体系最甜窗口；转入高潮期后胜率塌陷至 67%——升温先手 + 高潮第 2 日起禁买的组合正是"买在转势、卖在高潮"的实现。

**窗口（全天可出手，时段分级认证；试错笔规模锚 = 通用层 §2.5 试错档 5% ~ 目标 1/2，升级路径见 §2.5 先手仓升级）**：

| 时段 | 认证（当帧主源 = 大盘温度标签，分层温度纪律；短线当帧仅佐证） | 标的约束 |
|------|------|----------|
| 早盘段 10:00~11:00 | 当帧大盘温度标签 ∈ {修复, 升温} **且** `alignment == 共振` **且** 方向验证（见下）——开盘首小时假动作多，与通道 A2 回暖试错统一 10:00 后确认参与 | 标准画像（见出手条件 4） |
| 午后段 11:00~14:30 | 同早盘段认证 | **只做水下低吸**（`zdf` -5%~0% 或分时回踩关键支撑企稳，通用层 §0.6；水上 > +3% 不追——对齐通用层 §0.8 午后纪律） |
| 尾盘段 14:30~14:55 | 14:30 后最近两帧大盘温度标签均 ∈ {修复, 升温} **且** 当帧短线温度 ≥ 昨收短线温度（佐证；昨收 s **逐字取 `regime-state.json` 的 `history` 末条数值，禁止凭记忆 / 推测写昨收值**）**且** `alignment == 共振` | 标准画像 |

**方向验证（各时段共用）**：方向 ∈ 当帧 `attack_directions` / `attack_sectors`，且该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_daily_stats` 当日行，与通道 A2 同款要件）。

**标的画像（标准）**：六池来源、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且日内最高涨幅 ≤7%（`y1` 极值口径）、资金面硬条件与分时四信号不否决；过四层矩阵 ②③④ 与心法红线。

**与通用层 §2.2 / §0.8 的继承边界（单一口径，禁止按结论需要双向切换，教训 A.13）**：

- **继承**（前置否决照常执行）：§2.2 第 5 条（分时四信号）、第 6 条（资金-涨幅背离）、第 7 条（趋势衰竭——近 3 日累计 ≥15% 或连 3 日收阳，且当前涨幅 >+1% 且已从日内低点反弹超 2% → 禁买，教训 A.9）、第 9 条（资金面硬条件）。通道 C 先手的是**节点**、不是趋势末端的个股，趋势衰竭否决无通道豁免
- **豁免**（明文不适用，禁止再引用）：§2.2 第 8 条（题材阶段错配）与 §0.8 执行节奏（Day 2+ 早盘不急追 / 午后水下低吸窗口）。通道 C 买的是市场节点 + 方向强度——方向验证本身要求板块涨停数居全市场前三，一致加强段主线正是主要候选池；时段分级认证（10:00 后确认 + 当帧标签 + 共振 + 方向验证）已替代 §0.8 的企稳等待。若叠加题材窗口 / 企稳要求，通道 C 在其设计的主要场景下无标的可买、名存实亡

**风控（试错笔专属）**：确认失败（当日收盘 s < 55）或次日开盘走弱 → **次日无条件离场，不等止损位**；常规止损 / 时间止损照常生效且优先级更高。隔夜黑天鹅同冰点通道处置（止损照常，试错仓封顶损失）。

**证据分级（观察级条款）**：通道 C 是未经历史回放验证的前向假设（当帧历史数据不存在）。每次出手的理由在盯盘总结正文与摘要行操作描述中以前缀 `channel=C` 标注（确认日 / 预备日区分标注，复盘从 `watch-summary-{date}.md` 汇总统计），**累计 ≥8 次后由用户依 T+2 验证成立率审定去留**；数据不足期间定位观察级，与通道 A/A2 同等待遇。

## 二C、通道 D：板块连强尾盘先手（节点许可窗口内的板块级机会通道）

> 设立依据：行情的常态在板块粒度（60 日内[板块]连续居前三 27 段 vs [短情]连续 ≥55 仅 5 段）；回放显示强势[板块] T+1 +1.32%/胜率 73%（n=60，样本含退潮 / 冰点 / 升温各节点日）。**适用节点按市场节点一票否决纪律执行**（心法 §三）：仅升温节点与冰点通道开放日——节点不对，题材再强不买。

**资格（全部满足）**：

1. **节点许可**（市场节点一票否决，心法 §三）：生效节点 ∈ {**升温节点**（回暖确认期 `current_state == "uptrend_ready"`，或升温第 1 日 `current_state == "defense"` + `up_count == 1`，或高潮第 1 日 `current_state == "uptrend"` + `uptrend_first_day == true`），**冰点通道开放日**（`next_day_double_ice_ready` 或 `next_day_channel_open`），**冰点反弹延续日**（`next_day_rebound_channel_open == true`）}；**退潮期（非升温第 1 日、非反弹延续日）/ 降温期 / 高潮第 2 日起一律不适用**
2. **[板块]主升启动信号**：该板块已连续 ≥2 个交易日居市场热度前三（zt_count 排序；**昨日榜**取 `get_top_hot_spots --date <昨日> --limit 3`，**当日榜**取 `get_hot_spot_list --sort_by zt_count --limit 3` 实时榜——注意 `get_top_hot_spots` 的当日行盘中返回空、不可用于当日判定；并列涨停数按服务端排序取前 3，与回放统计同口径；当日榜在 T 日 14:30 判定，尾盘榜基本定型）
   **数据自愈纪律（与状态机自愈同哲学）**：连榜判定**只依赖上述行情接口**（服务端历史数据，任何时刻可当场重建），昨日复盘执行与否不影响通道 D 资格判定；接口调用失败才按 §0.8.1 数据限制处理（无法判定 → 不参与）
3. 该板块 ∉ 当帧撤退方向（`retreat_directions` / `retreat_sectors`）
4. 当天情绪闸不拦（`sentiment_label ∈ {保守, 偏保守}` 且 `alignment == 退潮` → 当日禁一切新开仓）：**升温节点（含高潮第 1 日）照常检查**（回暖 / 升温进程中两指标恶化属异常熔断）；**冰点通道开放日 / 冰点反弹延续日豁免**（2026-09-16 用户裁定：冰点进程内两指标触发 / 滞后属常态而非恶化信号，与冰点先手 A / A2 / B 豁免同源，通用层 §0.1）

**窗口与出手时点（时序纪律）**：

- **仅尾盘段 14:30~14:55 判定并出手**——先手 = 尾盘操作；回放口径（T+1 收益以 T 日收盘价为基准）只保护尾盘买入，T+1 开盘追买不在数据保护范围
- **禁止追认**：T 日尾盘信号通过但未出手 → 次日不追认昨日信号，按次日自身信号重新判定

**变体（红盘休整加码，观察级）**：连强 run 中该板块当日涨幅收窄至 0~1%（红盘但休整、未翻绿）且仍居前三（当日实时 `avg_zdf` 取 `get_hot_spot_list`）→ 视为更甜的参与位（T+1 +2.43%/100%，n=6，方向性线索）；**翻绿不是分歧、是走坏信号——禁止翻绿低吸**（翻绿后 T+2 -1.15%/0%，n=2）。

**标的画像**：板块内六池来源个股、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且**未涨停**（回放收益是板块核心成分均值，涨停股 T+1 可实现性未验证——禁追已涨停核心股）、资金面硬条件与分时四信号不否决；过四层矩阵 ②③④ 与心法红线。

**与通用层 §2.2 / §0.8 的继承边界（单一口径，禁止按结论需要双向切换，教训 A.13）**：

- **继承**（前置否决照常执行）：§2.2 第 5 条（分时四信号）、第 6 条（资金-涨幅背离）、第 9 条（资金面硬条件）
- **豁免**（明文不适用，禁止再引用）：§2.2 第 7 条（趋势衰竭）、第 8 条（题材阶段错配）与 §0.8 执行节奏。通道 D 买的就是连强 ≥2 日板块的成分股——成分股三连阳 / 题材处一致加强段是连强的必然结果而非例外，回放口径（T+1 +1.32% / 胜率 73%，n=60）已包含此类标的；通道 D 的趋势衰竭风险由板块级风控承接（连强终结信号 → 48 小时内兑现），不由个股第 7 条否决

**仓位**：试错档（5% ~ 目标 1/2，通用层 §2.5）；冰点通道开放日与冰点反弹延续日仓位上限折半（→ 5% ~ 7.5%），升温节点足额。

**风控**：[板块]连强终结信号（翻绿 / 跌出前三，T 日 14:30 以 `get_hot_spot_list` 实时榜可判定）→ **48 小时内兑现**（逢高分批，不抢跑——加速日 T+1 仍有惯性 n=8 +1.44%/100%，不拖延——翻绿后 T+2 转负）；常规止损 / 时间止损照常且优先级更高。

**证据分级**：连榜资格条款为回放数据级（✅ n=60/21/39，样本含各节点日——收窄后以升温 / 冰点日子集为主要参考）；红盘休整变体为观察级（⚠️ n=6）；每次出手的理由在盯盘总结正文与摘要行操作描述中以前缀 `channel=D` 标注（标注是否红盘休整变体，复盘从 `watch-summary-{date}.md` 汇总统计），**累计 ≥8 次后依 T+2 成立率审定去留**。

## 二E、通道 E：V 型修复尾盘先手（"冰点-大涨-回调-修复"四步形态修复日的预判通道，观察级）

> 设立动机：V 型第二腿强修复日（冰点 → 大涨 → 回调 → 修复，如 09-15 冰(10) → 09-16 涨(70) → 09-17 调(30) → 09-18 修复）若按退潮全禁等收盘双日确认，次日出手面对的大概率是高开加速后的次优买点——**先手预判换时间上的左侧**。风险对称：单日 s≥55 次日延续率仅 36%（8/22），故仅尾盘窗口 + 当帧大盘主源 + 小仓兜底。**阶段判定保持右侧（收盘序列），出手左侧化只走本通道**。

**资格（晨起全部满足，预计算字段只读）**：

1. `next_day_v_repair_ready == true`（**昨写今用，晨起读到 true 的当日即资格日，不是次日才生效**——与 `next_day_rebound_channel_open` 同时序；字段由昨收盘重放写入，`days_since_ice == 2` 为昨收值：昨日是"冰点-大涨-回调"的回调日（挂起第 2 日），今日即为修复日。状态 `defense` 且簇深 ≥2 且未达升温——冰点簇存活最后一天，窗口天然仅一日；其他通道开放日（A/A2/B/C/D 适用日）按既有通道走，不叠用）
2. 当天情绪闸不拦：`sentiment_label ∈ {保守, 偏保守}` 且 `alignment == 退潮` → 当日禁（**照常检查不豁免**——通道 E 不在冰点进程内，两指标恶化即真恶化）

**窗口与当帧认证（仅尾盘段 14:30~14:55 判定并出手，分层温度纪律）**：

- **主源**：14:30 后最近两帧大盘温度标签均 ∈ {修复, 升温}（尾盘当帧与收盘定格偏差最小）
- **佐证（不否决、只调仓）**：当帧短线温度 ≥ 昨收短线温度（昨收 s **逐字取 `regime-state.json` 的 `history` 末条数值**）不满足 → 仓位取区间下限 5%（原"折半"已并入通用层 5% 下限裁定，§2.5）
- **方向验证**：与通道 C 同款——方向 ∈ 当帧 `attack_directions` / `attack_sectors`，且该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_list --sort_by zt_count --limit 3` 当日实时榜）

**标的画像**：与通道 C 标准画像同款（六池来源、close>MA5、当日 `zdf` 0%~7% 且日内最高涨幅 ≤7%、资金面硬条件与分时四信号不否决、过四层矩阵 ②③④ 与心法红线）；**禁追已涨停核心股**（同通道 D 口径）。

**仓位**：单只 5% ~ 10%、合计 ≤20%（预判仓，错误成本封顶；5% 下限同通用层 §2.5 试错仓统一裁定，微仓凑单禁止）。

**衔接与风控**：

- 收盘确认 s ≥ 55 → 次日 `up_count == 1` = 升温第 1 日，此仓**视同通道 C 首仓提前建仓**，按通道 C 风控管理
- 收盘 s < 55（确认失败）→ **次日无条件离场，不等止损位**（同通道 C 试错笔风控）；常规止损 / 时间止损照常且优先级更高
- 禁止追认：尾盘信号通过但未出手 → 次日不追认昨日信号，按次日自身信号重新判定（同通道 D）

**证据分级（观察级条款）**：每次出手在盯盘总结正文与摘要行操作描述中以前缀 `channel=E` 标注，复盘从 `watch-summary-{date}.md` 汇总统计，**累计 ≥8 次后由用户依 T+2 验证成立率审定去留**；数据不足期间定位观察级，与通道 A/A2/C 同等待遇。**先验数据事实（2026-09-18 用户裁定设立，60 日回放）**：精确资格形态 n=2——07-23（尾盘认证通过、次日 -2.62% 入冰，假修复反例）/ 08-04（+1.79%，次日 s=75）；尾盘大盘主源认证样本内判别力为零（2/2 放行、结果 1:1），设立依据为家族效应（冰点簇存活背景 + 大盘修复 → 次日胜率 8/11=73% vs 无簇修复 5/11=45%，簇背景 +28pp）+ 小仓兜底 + 用户先手裁定，**非形态自身胜率验证**；风险场景（07-23 型：大盘标签修复、短线未跟的假修复 → 次日入冰）由"确认失败次日无条件离场"封顶损失。
