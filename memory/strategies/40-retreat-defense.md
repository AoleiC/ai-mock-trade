# 战法四：降温防守与升温出手（默认兜底）

> 适用节点：云端节点默认兜底册——**降温 / 连续降温**（禁一切新开仓、无例外——市场节点一票否决，节点不对题材再强不买，心法 §三）；**升温链（升温 / 连续升温）**的先手通道 C / D 见本分册 §二A / §二C；**冰点回暖**的修复试探通道 E/F 见本分册 §二E / §二F；冰点链分层试错通道见 `10-ice-point.md`（`a_open` 日通道 D 亦适用；首冰当日不操作）；高潮降温见 `30` 分册；**高潮链（高潮 / 连续高潮）禁一切新开仓（`realize_only`，只兑现），见 `20-main-uptrend.md`**。通用细则见核心层 `memory/dynamic-strategy.md`；买入细则（六池 / 买点 / 仓位阶梯）见买入手册 `memory/buy-playbook.md`（出手时必读）。

## 一、允许

- 持仓止损止盈、加速止盈、撤退方向减仓、**节点先手减仓**（通用层 §3.0：A 节点转弱晨起先手为数据支撑条，B/C 为观察级；浮盈持仓适用）（**风控不设时间窗**——卖出动作不受节点限制）
- **通道 C 升温节点先手**（当帧 = 升温（轻仓先手 · 待确认态）/ 连续升温（主出手窗口 · 可补足），条件见 §二A）——升温链内的市场级试错通道
- **通道 D 板块连强尾盘先手**（`d_open == true`：当帧 ∈ {升温, 连续升温, 冰点, 连续冰点, 冰点回暖}，条件见 §二C）——节点许可窗口内的板块级机会通道；**降温链 / 高潮降温 / 高潮链一律不适用**
- **通道 E 修复尾盘先手**（`ef_open == true`：当帧 = 冰点回暖（脱冰首日），条件见 §二E）——脱冰首日的尾盘小仓修复试探通道；仅 14:30~14:55 窗口、当帧大盘主源认证、小仓兜底
- **通道 F 修复盘中先手**（`ef_open == true`，与通道 E 同资格，条件见 §二F）——脱冰首日**盘中早段**（10:00~14:00）的左侧试错通道：形态已现、情绪未坏时出手，用当帧情绪与方向三件套替代尾盘大盘五档这个收盘口径近似
- 记录观察：emerging 方向在盯盘总结正文中照常记录（板块名 + 排名，只记录不出手，为节点切换与通道 D 资格积累数据，总纲 §7.2）

## 二、禁止

- **降温链一切新开仓，无例外**——市场节点一票否决（心法 §三）：节点不对，题材再强、板块再热都不买；冰点分层通道（A/A2/B）是冰点链节点专属，降温链不适用（资格见 `10-ice-point.md`）；**升温链（当帧 ∈ {升温, 连续升温}）不计入禁令**（`c_open`，云端节点直接表达）；**冰点回暖（`ef_open == true`，脱冰首日）同样豁免**——从冰点爬出来的反弹余韵是冰点博弈的延续、非真降温，**通道 F 盘中先手（§二F，10:00~14:00 窗口）+ 通道 E 尾盘先手（§二E，14:30~14:55 窗口）**，两条通道共享当日一笔试错额度（互斥规则见 §二F），仍非全天开放；高潮链（`realize_only`）只兑现不加仓
- 补足笔 / 加仓视同新开仓，同样禁止（降温链本就禁一切新开仓）；已有持仓的止损止盈不受影响

## 二A、通道 C：升温节点先手（升温链唯一开仓通道）

**资格（云端节点现算，`c_open == true`；当帧节点即资格——升温链内全天适用，无防御触发日不开通道一说）**：

1. **升温（上行首日 · 待确认态）**：当帧节点 = 升温——首升已发生、未持续确认，**轻仓先手**（试错档）
2. **连续升温（确认态）**：当帧节点 = 连续升温——上行已持续，**主出手窗口，可补足**（买在升温链、在高潮链兑现——高潮链只兑现不加仓，由 `20` 分册节点减仓管理退出）

> 设计动机：升温节点先手用轻仓 + 节点认证换时间上的左侧。云端节点的链式转移（升温 → 连续升温 → 高潮）天然承担防抖：首日待确认态轻仓、确认态可补足——出手可以左侧（轻仓先手），节点判定保持云端权威（不本地预测）。升温期板块 T+1 胜率 100%（n=6，旧口径回放）是全体系最甜窗口；进入高潮链后兑现——升温先手 + 高潮链禁买的组合正是"买在转势、卖在高潮"的实现。

**窗口（全天可出手，时段分级认证；试错笔规模锚 = 买入手册 §2.5 试错档 5% ~ 目标 1/2，升级路径见买入手册 §2.5 先手仓升级）**：

| 时段 | 认证（当帧主源 = 大盘五档 `temperature_level`，结构化字段；短线当帧仅佐证） | 标的约束 |
|------|------|----------|
| 早盘段 10:00~11:00 | 当帧 `temperature_level ∈ {常温, 偏热, 亢奋}` **且** `alignment ∈ {双强, 胶着}`（短线好 × 大盘非弱）**且** 方向验证（见下）——开盘首小时假动作多，与通道 A2 共振试错统一 10:00 后确认参与 | 标准画像（见出手条件 4） |
| 午后段 11:00~14:30 | 同早盘段认证 | **只做水下低吸**（`zdf` -5%~0% 或分时回踩关键支撑企稳，通用层 §0.6；水上 > +3% 不追——对齐买入手册 §0.8 午后纪律） |
| 尾盘段 14:30~14:55 | 14:30 后最近两帧 `temperature_level` 均 ∈ {常温, 偏热, 亢奋} **且** `alignment ∈ {双强, 胶着}`；**短线当帧仅佐证（不否决、只调仓）**：当帧短线温度 ≥ 昨收短线温度（昨收 s **逐字取市场节点 JSON 的 `yesterday_score`，禁止凭记忆 / 推测写昨收值**）不满足 → **仓位取试错档下限 5%**（同 §二E 口径，下限见买入手册 §2.5），**不否决出手**（防退潮职责由本行前两条认证承担：真退潮时大盘五档转弱 / 对齐双弱，双重否决，第三条冗余；表头"短线当帧仅佐证"即此意） | 标准画像 |

**方向验证（各时段共用）**：方向由盘面数据直查说话，**不**依赖当帧 `attack_directions` / `attack_sectors` 名单（名单非门槛，通用层 §0.2）：
- **硬前提（不满足则整条通道 C 不出手）**：该方向不在当帧 `retreat_directions` / `retreat_sectors` 名单内；同帧既在 attack 又在 retreat 的方向（板块内部大票出货、小票反抽的分裂）**一律按撤退处理禁买**（与通道 A2 同款硬前提）
- **属性标签不作方向主源**：业绩线 / 并购重组这类"为什么涨"的说明性标签不作为方向判定的独立命中
- **要件 1（板块强度）**：该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_daily_stats` 当日行 / `get_hot_spot_list --sort_by zt_count --limit 3`）
- **要件 2（集体上攻）**：该板块风向标（`attack_sectors[].key_stocks`，服务端查表填充）中 ≥2 只当日 `zdf > 3%`

**标的画像（标准）**：六池来源、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且日内最高涨幅 ≤9%（`y1` 极值口径）、资金面硬条件与分时四信号不否决；过四层矩阵 ②③④ 与心法红线。

**与买入手册 §2.2 / §0.8 的继承边界（单一口径，禁止按结论需要双向切换，教训 A.13）**：

- **继承**（前置否决照常执行）：买入手册 §2.2 第 5 条（分时四信号）、第 6 条（资金-涨幅背离）、第 7 条（趋势衰竭——衰竭画像任一命中即适用（§2.2 第 7 条扩展口径：近 3 日累计 ≥15% / 近 5 日累计 ≥25% / 近 5 日内 ≥30% 急涨段未回踩 MA5 / 连 3 日收阳），且当前涨幅 >+1% 且已从日内低点反弹超 2% → 禁买，教训 A.9）、第 9 条（资金面硬条件）。通道 C 先手的是**节点**、不是趋势末端的个股，趋势衰竭否决无通道豁免
- **豁免**（明文不适用，禁止再引用）：买入手册 §2.2 第 8 条（题材阶段错配）与 §0.8 执行节奏（Day 2+ 早盘不急追 / 午后水下低吸窗口）。通道 C 买的是市场节点 + 方向强度——方向验证本身要求板块涨停数居全市场前三，一致加强段主线正是主要候选池；时段分级认证（10:00 后确认 + 当帧五档 + 对齐 + 方向验证）已替代 §0.8 的企稳等待。若叠加题材窗口 / 企稳要求，通道 C 在其设计的主要场景下无标的可买、名存实亡

**风控（试错笔专属）**：确认失败（次日云端节点转降温 / 回落）或次日开盘走弱 → **次日无条件离场，不等止损位**；常规止损 / 时间止损照常生效且优先级更高。隔夜黑天鹅同冰点通道处置（止损照常，试错仓封顶损失）。

**证据分级（观察级条款）**：通道 C 是未经历史回放验证的前向假设（当帧历史数据不存在）。每次出手的理由在盯盘总结正文与摘要行操作描述中以前缀 `channel=C` 标注（升温 / 连续升温档区分标注，复盘从 `watch-summary-{date}.md` 汇总统计），**累计 ≥8 次后由用户依 T+2 验证成立率审定去留**；数据不足期间定位观察级，与通道 A/A2 同等待遇。

## 二C、通道 D：板块连强尾盘先手（节点许可窗口内的板块级机会通道）

> 设立依据：行情的常态在板块粒度（60 日内[板块]连续居前三 27 段 vs [短情]连续 ≥55 仅 5 段）；回放显示强势[板块] T+1 +1.32%/胜率 73%（n=60，样本含退潮 / 冰点 / 升温各节点日）。**适用节点按市场节点一票否决纪律执行**（心法 §三）：仅升温节点与冰点通道开放日——节点不对，题材再强不买。

**资格（全部满足）**：

1. **节点许可**（市场节点一票否决，心法 §三）：`d_open == true`（当帧 ∈ {升温, 连续升温, 冰点, 连续冰点, 冰点回暖}，云端现算）；**降温链 / 高潮降温 / 高潮链一律不适用**
2. **[板块]主升启动信号**：该板块已连续 ≥2 个交易日居市场热度前三（zt_count 排序；**昨日榜**取 `get_top_hot_spots --date <昨日> --limit 3`，**当日榜**取 `get_hot_spot_list --sort_by zt_count --limit 3` 实时榜——注意 `get_top_hot_spots` 的当日行盘中返回空、不可用于当日判定；并列涨停数按服务端排序取前 3，与回放统计同口径；当日榜在 T 日 14:30 判定，尾盘榜基本定型）
   **数据自愈纪律**：连榜判定**只依赖上述行情接口**（服务端历史数据，任何时刻可当场重建），昨日复盘执行与否不影响通道 D 资格判定；接口调用失败才按买入手册 §0.8.1 数据限制处理（无法判定 → 不参与）
3. 该板块 ∉ 当帧撤退方向（`retreat_directions` / `retreat_sectors`）
4. 当天情绪闸不拦（`sentiment_label ∈ {保守, 偏保守}` 且 `alignment == 双弱` → 当日禁一切新开仓）：**升温链照常检查**（升温链中两指标恶化属异常熔断）；**冰点链 / 冰点回暖豁免**（冰点链内两指标触发 / 滞后属常态而非恶化信号，与冰点先手 A / A2 / B 豁免同源，通用层 §0.1）

**窗口与出手时点（时序纪律）**：

- **仅尾盘段 14:30~14:55 判定并出手**——先手 = 尾盘操作；回放口径（T+1 收益以 T 日收盘价为基准）只保护尾盘买入，T+1 开盘追买不在数据保护范围
- **禁止追认**：T 日尾盘信号通过但未出手 → 次日不追认昨日信号，按次日自身信号重新判定

**变体（红盘休整加码，观察级）**：连强 run 中该板块当日涨幅收窄至 0~1%（红盘但休整、未翻绿）且仍居前三（当日实时 `avg_zdf` 取 `get_hot_spot_list`）→ 视为更甜的参与位（T+1 +2.43%/100%，n=6，方向性线索）；**翻绿不是分歧、是走坏信号——禁止翻绿低吸**（翻绿后 T+2 -1.15%/0%，n=2）。

**标的画像**：板块内六池来源个股、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且**未涨停**（回放收益是板块核心成分均值，涨停股 T+1 可实现性未验证——禁追已涨停核心股）、资金面硬条件与分时四信号不否决；过四层矩阵 ②③④ 与心法红线。

**与买入手册 §2.2 / §0.8 的继承边界（单一口径，禁止按结论需要双向切换，教训 A.13）**：

- **继承**（前置否决照常执行）：买入手册 §2.2 第 5 条（分时四信号）、第 6 条（资金-涨幅背离）、第 9 条（资金面硬条件）
- **豁免**（明文不适用，禁止再引用）：买入手册 §2.2 第 7 条（趋势衰竭）、第 8 条（题材阶段错配）与 §0.8 执行节奏。通道 D 买的就是连强 ≥2 日板块的成分股——成分股三连阳 / 题材处一致加强段是连强的必然结果而非例外，回放口径（T+1 +1.32% / 胜率 73%，n=60）已包含此类标的；通道 D 的趋势衰竭风险由板块级风控承接（连强终结信号 → 48 小时内兑现），不由个股第 7 条否决

**仓位**：试错档（5% ~ 目标 1/2，买入手册 §2.5）；冰点链与冰点回暖日仓位上限折半（→ 5% ~ 7.5%），升温链足额。

**风控**：[板块]连强终结信号（翻绿 / 跌出前三，T 日 14:30 以 `get_hot_spot_list` 实时榜可判定）→ **48 小时内兑现**（逢高分批，不抢跑——加速日 T+1 仍有惯性 n=8 +1.44%/100%，不拖延——翻绿后 T+2 转负）；常规止损 / 时间止损照常且优先级更高。

**证据分级**：连榜资格条款为回放数据级（✅ n=60/21/39，样本含各节点日——收窄后以升温 / 冰点日子集为主要参考）；红盘休整变体为观察级（⚠️ n=6）；每次出手的理由在盯盘总结正文与摘要行操作描述中以前缀 `channel=D` 标注（标注是否红盘休整变体，复盘从 `watch-summary-{date}.md` 汇总统计），**累计 ≥8 次后依 T+2 成立率审定去留**。

## 二E、通道 E：修复尾盘先手（冰点回暖日的预判通道，观察级）

> 设立动机：脱冰首日（云端节点 = 冰点回暖：昨日冰点链、今日入中区，如 09-15 冰(10) → 09-16 涨(70) 的次日回升段）若等收盘确认再出手，次日面对的大概率是高开加速后的次优买点——**先手预判换时间上的左侧**。风险对称：单日 s≥55 次日延续率仅 36%（8/22，旧口径），故仅尾盘窗口 + 当帧大盘主源 + 小仓兜底。**节点判定保持云端权威（收盘定格），出手左侧化只走本通道**。

**资格（云端节点现算）**：

1. `ef_open == true`（当帧节点 = **冰点回暖**——脱冰首日即修复窗口，随当帧实时判定；窗口天然仅当日，节点转入降温 / 升温链后自动关闭）
2. 当天情绪闸不拦：`sentiment_label ∈ {保守, 偏保守}` 且 `alignment == 双弱` → 当日禁（**照常检查不豁免**——冰点回暖日已出冰点链，两指标恶化即真恶化）

**窗口与当帧认证（仅尾盘段 14:30~14:55 判定并出手，分层温度纪律）**：

- **主源**：14:30 后最近两帧 `temperature_level` 均 ∈ {常温, 偏热, 亢奋}（尾盘当帧与收盘定格偏差最小）
- **佐证（不否决、只调仓）**：当帧短线温度 ≥ 昨收短线温度（昨收 s **逐字取市场节点 JSON 的 `yesterday_score`**）不满足 → 仓位取区间下限 5%（下限口径见买入手册 §2.5）
- **方向验证**（与通道 C / A2 同款）：方向由盘面数据直查说话，**不**依赖当帧 `attack_directions` / `attack_sectors` 名单（名单非门槛，通用层 §0.2）；硬前提 = 该方向不在当帧 `retreat_directions` / `retreat_sectors` 名单内（同帧冲突按撤退禁买）；要件 1 = 板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_list --sort_by zt_count --limit 3` 当日实时榜）；要件 2 = 板块风向标（`attack_sectors[].key_stocks`，服务端查表填充）≥2 只当日 `zdf > 3%`；属性标签（业绩线 / 并购重组）不作方向主源

**标的画像**：与通道 C 标准画像同款（六池来源、close>MA5、当日 `zdf` 0%~7% 且日内最高涨幅 ≤9%、资金面硬条件与分时四信号不否决、过四层矩阵 ②③④ 与心法红线）；**禁追已涨停核心股**（同通道 D 口径）。

**仓位（背景加权渐进）**：基础档单只 5% ~ 10%、合计 ≤20%（预判仓，错误成本封顶；5% 下限同买入手册 §2.5 试错仓统一口径，微仓凑单禁止）。**升降档**：`channel=E` 累计样本 n ≥ 8 且 T+2 成立率 ≥ 60% → 升至单只 10% ~ 15%、合计 ≤30%（依据：冰点簇存活背景 + 大盘修复的家族胜率 8/11=73% vs 无簇修复 5/11=45%，+28pp 边缘值得中档仓）；成立率 < 40% → 降为固定单只 5% 并提请用户审定通道存废；40% ~ 60% 之间维持基础档。

**衔接与风控**：

- 次日云端节点 = 升温链（`c_open`）→ 此仓**视同通道 C 首仓提前建仓**，按通道 C 风控管理
- 次日云端节点回落（回冰 / 降温链，确认失败）→ **无条件离场，不等止损位**（同通道 C 试错笔风控）；常规止损 / 时间止损照常且优先级更高
- 禁止追认：尾盘信号通过但未出手 → 次日不追认昨日信号，按次日自身信号重新判定（同通道 D）
- **与通道 F 的互斥**：同一修复日 F（盘中）与 E（尾盘）共享当日一试错笔额度，谁先成立谁执行，已出手后当日不再开第二条（规则见 §二F）

**证据分级（观察级条款）**：每次出手在盯盘总结正文与摘要行操作描述中以前缀 `channel=E` 标注，复盘从 `watch-summary-{date}.md` 汇总统计，**累计 ≥8 次后由用户依 T+2 验证成立率审定去留与仓位升降（升降档标准见上方仓位条款）**；数据不足期间定位观察级，与通道 A/A2/C 同等待遇。**先验数据事实（60 日回放）**：精确资格形态 n=2——07-23（尾盘认证通过、次日 -2.62% 入冰，假修复反例）/ 08-04（+1.79%，次日 s=75）；尾盘大盘主源认证样本内判别力为零（2/2 放行、结果 1:1），设立依据为家族效应（冰点簇存活背景 + 大盘修复 → 次日胜率 8/11=73% vs 无簇修复 5/11=45%，簇背景 +28pp）+ 小仓兜底，**非形态自身胜率验证**；风险场景（07-23 型：大盘标签修复、短线未跟的假修复 → 次日入冰）由"确认失败次日无条件离场"封顶损失。

## 二F、通道 F：修复盘中先手（冰点回暖日早段的左侧试错通道，观察级）

> **设立动机**：通道 E 把冰点回暖日的出手权锁在尾盘 14:30~14:55，但修复日的高胜率窗口在**盘中早段**——形态已现（三条主线资金共振、涨停梯队完整）、情绪未坏（短线中性以上 + 对齐双强 / 胶着）；等尾盘确认时情绪往往已转差——实例形态：盘中早段情绪中性偏激进、主线资金共振、涨停梯队完整，到尾盘帧情绪已滑至偏保守 + 对齐双弱，通道 E 被情绪闸拦下、**全天零权限**。通道 F 把形态判别前移到盘中：**用当帧"情绪 + 对齐 + 方向三件套"替代"尾盘大盘五档"这个收盘口径的近似**——真修复的早段能试错，假修复（大盘五档回暖但短线没跟）被情绪条件过滤。
>
> **与通道 E 的分工（非二选一、共享额度）**：E 要求"修复已被尾盘确认"（情绪不许塌：保守 / 偏保守 + 对齐双弱 → 当日禁，照常检查不豁免）；F 要求"修复正在进行"（情绪双正向：中性以上 + 对齐双强 / 胶着）。同一资格日两条通道对同一形态在不同时间窗取不同证据，**谁先成立谁执行，当日只出一笔**。

**资格（晨起 + 当帧，全部满足）**：

1. `ef_open == true`（当帧节点 = 冰点回暖，与通道 E 同一资格、同一形态判别；字段语义见 `00-market-node.md`）
2. **窗口：10:00 之后 ~ 14:00 之前**（避开开盘半小时的信息噪声；尾盘 25 分钟归通道 E，两通道时段不重叠）
3. **当帧情绪双正向**（要求严于通用层 §0.1 的最低要求，非豁免）：
   - `sentiment_label ∈ {中性, 偏激进, 激进}`——保守 / 偏保守 → 当日不出手
   - `sentiment_capital_alignment ∈ {双强, 胶着}`——普涨 / 逆势 / 双弱 → 当日不出手
4. **方向验证**（与通道 E / A2 同款，方向由盘面数据直查、不依赖当帧名单，通用层 §0.2）：硬前提 = 该方向不在当帧 `retreat_directions` / `retreat_sectors` 内（同帧冲突按撤退禁买）；要件 1 = 板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_list --sort_by zt_count --limit 3` 实时榜）；要件 2 = 板块风向标（`attack_sectors[].key_stocks`）≥2 只当日 `zdf > 3%`
5. **四层矩阵 ②③④ 全部通过**（①层由冰点回暖节点豁免满足；账户层 `position_limit` 照常硬约束，limit = 0 时不出手）

**标的画像**：与通道 E 同款（六池来源、close>MA5、当日 `zdf` 0%~7% 且日内最高涨幅 ≤9%、资金面硬条件与买入侧分时分级（买入手册 §2.2 第 5 条）不否决、过四层矩阵 ②③④ 与心法红线）；**禁追已涨停核心股**（同通道 D 口径）。

**仓位**：单只 5%（试错档固定，不随情绪强度放大——F 是形态预判仓，风险敞口封顶）；当日最多 1 笔；**与通道 E 不叠加**（当日一试错笔额度共享，先成立者占用）；补足笔 / 加仓视同新开仓，同样受"当日一笔"限制。

**与通道 E 的互斥细则**：F 在盘中成立、E 在尾盘成立，**先成立者占用当日额度**；已出手后当日不再开第二条通道（同一形态不重复预判）；两条通道均未成立 → 当日无预判笔（配额制的合法空手情形之一，记账见通用层「试错执行纪律」）。

**风控（与通道 E 同款封顶逻辑）**：

- 次日云端节点 = 升温链（`c_open`）→ 此仓**视同通道 C 首仓提前建仓**，按通道 C 风控管理
- 次日云端节点回落（回冰 / 降温链，确认失败）→ **无条件离场，不等止损位**（同 E 试错笔风控）；常规止损 / 时间止损照常且优先级更高
- 禁止追认：盘中条件不成立而事后成立，不追认，按次日自身信号重新判定

**风险边界**：

- 假修复过滤：07-23 型（大盘修复、短线没跟 → 次日 -2.62% 入冰）被资格 3 的情绪双正向过滤（保守档 + 对齐双弱 → 不开）；**未被过滤的变体 = 早段情绪偏激进但尾盘修复失败**，由"确认失败次日无条件离场"封顶损失
- 与"降温链追当日最强方向"的区别（10-16 军工反例：当日 attack 方向买入，10-19 / 10-20 该方向连日进撤退名单被痛打）：F 要求冰点回暖节点（昨日冰点链背景）+ 情绪双正向 + 方向不在撤退名单 + 三件套，门槛高于"当日最强方向"

**证据分级（观察级条款）**：每次出手在盯盘总结正文与摘要行操作描述中以前缀 `channel=F` 标注，复盘从 `watch-summary-{date}.md` 汇总统计，**累计 ≥8 次后由用户依 T+2 验证成立率审定去留与仓位升降**；样本与通道 E **独立统计**（形态与出手时点不同，不得混样本）；数据不足期间定位观察级。
