# 市场节点（云端权威）与通道资格映射（裁决层）

> **今天处于什么节点的唯一权威判定在云端**（mock-trade 主仓 AI 盘面分析）：盘中实时节点 = `get_intraday_analysis` 出参的 `market_node` 字段；日级节点链 = `/market_node_series` 结构化序列。本地读取入口 = `market.read_market_node`（盘中帧 + 日级链的无状态组合，`skills/mock/market.ts`）。**agent 只读云端输出，禁止手工推演节点、禁止在节点上叠加任何本地分值条件与阈值**。
>
> 本文件是通道资格映射（§三）的**人审表述**，与 `skills/mock/market.ts` 的 `readMarketNode` 派生代码同步修订——二者不一致时以代码为准并立即修复。
>
> **术语粒度规范**：节点均为 **[短情]粒度**（短线情绪温度序列），与 [板块] 粒度（热点分类）严格区分；"主升"一词只归 [板块] 使用。

## 一、云端节点词表与操作语义（十词，权威源 = 主仓设计文档 §五）

区位阈值：**冰点区 ≤20，高潮区 ≥75，中区 21~74**（云端状态机 `machine`：区位优先 + 链式转移，持平延续昨日节点）。

| 节点 | 语义 | 操作映射（主仓 §5.5，当日行为基调） |
|------|------|--------------------------------------|
| 冰点 | 当日入冰点区（首冰） | 冰点博弈窗口，分层低吸试探 |
| 连续冰点 | 昨日也在冰点区（"二冰三冰"的区位表达，深冰语义由"连续"承载） | 同上（通道 A 全天开放） |
| 冰点回暖 | 中区且昨日冰点链（脱冰首日，不问涨幅） | 脱冰首日，修复试探小仓（通道 E/F 窗口） |
| 升温 | 中区首升（上行首日 · 待确认态） | 轻仓先手 |
| 连续升温 | 上行已持续（确认态） | 主出手窗口，可补足 |
| 高潮 | 当日入高潮区（≥75，稀有） | 惯性日只兑现不加仓 |
| 连续高潮 | 昨日也在高潮区 | 同上 |
| 高潮降温 | 中区且昨日高潮链（高潮回落未崩） | 兑现 / 减仓事件日 |
| 降温 | 中区回落首日（无链） | 防守、禁新仓 |
| 连续降温 | 回落已持续（链越长越严） | 同上 |

配套字段（云端一并下发）：

- `temperature_level`：大盘五档（冰点 / 偏冷 / 常温 / 偏热 / 亢奋，纯分值映射）——当帧大盘条件的结构化来源（通道 B"大盘先好"、通道 C/E 时段认证用 `{常温, 偏热, 亢奋}`），替代旧标签文本；
- `temperature_delta`：当帧大盘分值 − 昨收差值（机读参考，仅日志展示，不进判定）；
- 日级链 `sentiment_chain: [{date, score, node}]`：通道资格的昨日锚与复盘叙述源；`market_chain` 的 `has_alert`（DTA 守门员告警）仅日志参考。

## 二、判定输入与生效时序

- **输入**：全部来自云端——盘中实时节点（当帧最新短线情绪分值 × 前一交易日定格锚实时计算）与日级收盘定格链（当日最晚一帧 success 的 sentiment_score）。本地零实现、零缓存、零重放、零附加条件；
- **通道资格随当帧节点实时判定**：当日操作语义消费当帧 `market_node`——短线情绪怎么动节点就怎么动、通道就怎么开（对齐主仓"盘中盘后统一单引擎、不等待收盘"的哲学）。昨日链节点仅用于同类通道分层（B 与 A 的区分）与当帧缺位降级；
- **无"昨写今用"预计算**：旧 `next_day_*` 预计算字段与本地状态文件已退役，通道资格每轮由 `read_market_node` 现算；
- **复盘零节点职责**：复盘不推进 / 不重建 / 不对账节点状态，节点词直接引用云端返回值（只读展示）。

## 三、通道资格映射（本地消费规则，纯云端节点词组合、零分值条件）

晨起 / 每轮由 `market.read_market_node` 组合派生（字段名即代码输出，agent 只读）：

| 通道 | 资格（云端词组合） | 语义来源 |
|------|--------------------|----------|
| `a_open`（通道 A 冰中试错） | 昨日 = **连续冰点** 且 当帧 ∈ {冰点, 连续冰点} | §一"冰点博弈窗口，分层低吸试探"——双冰背景 + 当日仍冰；当帧已出冰则自动转入 E/F 或 C 窗口 |
| `a2_open`（通道 A2 共振试错 / 参与） | 昨日 ∈ {冰点, 连续冰点} | 首冰次日与双冰后通用；当帧分流（两件套）照旧 |
| `b_open`（通道 B 尾盘低吸） | 昨日 = **冰点**（非连续） | 首冰次日无共振方向的尾盘低吸；"大盘先好"变体条件 = `temperature_level ∈ {常温, 偏热, 亢奋}` |
| `c_open`（通道 C 升温先手） | 当帧 = **升温**（轻仓先手 · 待确认态）或 **连续升温**（主出手窗口 · 可补足） | §一两档语义直接作为仓位分档（40 §二A） |
| `d_open`（通道 D 板块连强尾盘） | 当帧 ∈ {升温, 连续升温, 冰点, 连续冰点, 冰点回暖} | 节点许可窗口内的板块级机会；连榜判定不变（行情接口直查） |
| `ef_open`（通道 E 尾盘 / F 盘中修复先手） | 当帧 = **冰点回暖** | §一"脱冰首日，修复试探小仓"——窗口即出冰当日（本地 V 型四步形态组合已废弃） |

卖侧基调（随节点直接派生）：

- `forbidden_new_position`：当帧 ∈ {降温, 连续降温, 高潮降温, 高潮, 连续高潮} → **禁新开仓**（环境分层减仓等持仓侧纪律照常，风控不设时间窗）；
- `realize_only`：当帧 ∈ {高潮, 连续高潮, 高潮降温} → **只兑现不加仓**（旧"高潮第 1 日可买"特例与 s≥70 预警档已取消——高潮链一律兑现）。

旧通道 G（回暖试探）**已退役**：云端链下"冰点回暖次日续升 = 连续升温"即 C 主窗口，旧状态机 55 门槛制造的"双温死角"（40~54 无通道）不复存在，试探语义由 C 的"升温 = 轻仓先手"档承接。

## 四、读取契约与降级（`market.read_market_node`，登录态）

**出参**（code 200）：

```json
{
  "market_node": "连续升温",      // 当帧实时节点（可 null——LLM 失败帧）
  "node_degraded": false,          // 当帧节点缺位时 true（effective_node 已退回昨日链末节点）
  "effective_node": "连续升温",    // 通道资格与展示所用节点
  "temperature_level": "常温",     // 当帧大盘五档
  "yesterday_node": "升温",        // 昨日收盘定格节点（通道分层锚）
  "yesterday_score": 45,
  "yesterday_date": "2026-11-13",
  "prev_node": "冰点回暖",         // 前日节点（叙述参考）
  "today_included": false,         // 日级链是否已含今日（盘中 false / 盘后 true）
  "forbidden_new_position": false,
  "realize_only": false,
  "channels": { "a_open": false, "a2_open": false, "b_open": false, "c_open": true, "d_open": true, "ef_open": false }
}
```

**降级口径**：

- **当帧节点缺位**（LLM 失败帧 / 9:30~9:37 首帧未生成）：`node_degraded=true`，`effective_node` 取昨日链末节点——降级期间盘面按总纲 §5.2 / §5.3 退化流程处理，**新开仓跳过**；
- **整体读取失败**（盘中帧与日级链均不可达）：返回 `code 502` 防守信封——当日按防守处理并记录，**下轮自动重试**；不设本地文本解析兜底；
- **主仓补跑历史后**本仓下一轮自然恢复，无须任何本地重建。

## 五、阈值与规则变更纪律

- 节点词表 / 区位阈值（≤20 / ≥75）/ 节点 × 操作映射（§一）以**主仓设计文档**（`docs/2026-11-13-temperature-alignment-node-redesign.md`）为唯一权威源，本仓不维护副本判定、不得单边修改；
- 本仓 §三 通道资格映射与 §四 契约变更须**用户批准**，且代码（`skills/mock/market.ts`）与本文档**同步修订**——只改一处即判定漂移；
- 对齐词表（共振五词：双强 / 普涨 / 胶着 / 逆势 / 双弱）同源云端，alignment 消费点一律用五词，旧六档词（共振 / 回暖 / 磨底 / 逆势抱团 / 退潮）全部退役。
