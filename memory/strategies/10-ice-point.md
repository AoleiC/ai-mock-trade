# 战法一：冰点博弈（`ice_point`）

> **出手的大前提是冰点进程节点**：先由状态机预计算字段判定"本轮冰点走到第几天"，再决定当日是否有通道、走哪条通道。**方向选择的大前提是共振回暖**：出手标的买"当帧共振回暖方向"，不买单日逆势强势（数据依据见 §六：末冰日逆势 top3 在反弹日的留存率仅 19%）。通用细则见 `memory/dynamic-strategy.md`。
>
> 分层资格（均由 `skills/journal` 代码预计算，agent 只读字段、禁止手工推演）：
> - **单冰日（本轮首个冰点日）**：**不操作**（首冰当日收盘才定格进状态，当日盘中处于前一阶段规则管辖，天然无冰点通道）
> - **潜在双冰日**：晨起 `next_day_double_ice_ready == true`（昨收盘冰点且簇深 1）→ 双路径（回暖试错 / 尾盘低吸）
> - **双冰确立后的交易日**：晨起 `next_day_channel_open == true`（昨收盘冰点且簇深 ≥2）→ **全天开放**试错通道，**无簇深上限**——冰点簇不终结（连续 3 个交易日无冰才清零），通道持续开放；极端长熊的防御由出手纪律兜底（无共振 / 非主线不出手、出手仅小仓试错）；通道开放日通道 D 亦适用（节点许可，`40` §二C）

## 一、出手窗口（按冰点进程分层；风险由仓位约束兜底——轻仓试错、档位上限、同板块合并同方向 ≤50%）

- **单冰日**：不操作，仅记录观察
- **潜在双冰日**（昨收盘单冰）：
  - **通道 A2 回暖试错**：当日**10:00 后**当帧大盘温度标签 ∈ {修复, 升温}（回暖，主源大盘当帧）+ 共振三件套 → 小仓位试错买当帧共振方向；午后段只做水下低吸。10:00 前不看盘不动手（防早盘假拉起）
  - **通道 B 双冰尾盘低吸**：全天仍冰（当帧大盘温度标签 ∈ {冰点, 退潮}）→ **尾盘 14:30~14:55 可考虑低吸，标的仅限贯穿性主线**（要件见 §三）
  - 两条路径按当帧大盘温度标签二选一
- **双冰确立后的交易日**（昨收盘簇深 ≥2）：**全天开放通道**：
  - 当帧回暖（大盘当帧标签 ∈ {修复, 升温}）→ 按通道 A2 买**当帧共振回暖方向**；回暖确认后仓位可放宽（试错档 → 标准档）
  - 当帧仍冰（大盘当帧标签 ∈ {冰点, 退潮}）→ 按通道 A 冰中低吸，**标的仅限贯穿性主线**；单日逆势强只记录不出手
- **极端长熊（连冰极深）**：通道不封，但严格执行"非当帧共振 / 非贯穿性主线不出手 + 出手仅小仓试错"纪律——连续深冰意味着系统性风险，出手标准只应更严，无需另设通道上限
- **逆势观察记录（三通道共用输入）**：冰中时段的当日逆势强势板块（涨停居前 3 但非贯穿性主线）**只记录不出手**——次日回暖帧若该方向升级进当帧共振名单（attack 名单 + 涨停居前 3 + 风向标集体上攻），即按通道 A2 方向验证出手；记录写入盯盘总结正文（板块名 + 排名 + 次日验证结果复盘回填）

## 二、通道 A 出手条件（双冰确立后的交易日，冰中低吸，四项同时，任一缺证据即不出手）

1. **通道资格**：`next_day_channel_open == true`
2. **当帧仍冰（主源 = 当帧大盘温度，分层温度纪律）**：当帧 `get_intraday_analysis().temperature_label` ∈ {冰点, 退潮}（大盘当帧稳定；短线当帧 `sentiment_score` 跳变剧烈仅作佐证不作 gating）；当帧大盘标签 ∈ {修复, 升温}（回暖）转通道 A2 共振逻辑；**帧缺位 / 当日 LLM 整体缺位 → 无证据 → 不出手**
3. **贯穿性主线要件**（替代原"冰中突围要件"）：标的所属板块为**贯穿性主线**——近 10 个交易日内 ≥3 次进市场热度前三（`get_hot_spot_rotation --days 10` 服务端历史榜直查，与 `30` 分册贯穿性主线同口径）。**单日逆势强（涨停居前 3 但不满足主线要件）不买**——数据依据：反弹日留存的 5 个席位全部为主线性质，单日逆势脉冲留存为 0（§六）
4. **标的过心法红线 + 当日层 LLM 两指标不禁止**；标的画像：六池来源、close>MA5，**买主线内的强势回踩，不买跌幅**（MA5 下行一票否决）

## 二A、通道 A2 出手条件（共振回暖主通道，四项同时，任一缺证据即不出手）

1. **通道资格 + 窗口**：潜在双冰日（`next_day_double_ice_ready`，限 **10:00~14:55**）或双冰确立后的交易日（`next_day_channel_open`，全天段）；9:36 前当日 LLM 未生成，无证据不出手（总纲 §5.3）
2. **当帧已回暖（主源 = 当帧大盘温度，分层温度纪律）**：当帧 `get_intraday_analysis().temperature_label` ∈ {修复, 升温}（大盘当帧稳定；短线当帧跳变剧烈仅作佐证）；**帧缺位 / 当日 LLM 整体缺位 → 无证据 → 不出手**；**午后段限水下低吸**（`zdf` -5%~0% 或分时回踩关键支撑企稳，§0.6；水上 > +3% 不追）
3. **共振回暖三件套（方向 = 当帧共振，非逆势记忆）**：方向 ∈ 当帧 `attack_directions` / `attack_sectors` 名单，**且**该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_daily_stats` 当日行），**且**该板块风向标 `key_stocks` 中 ≥2 只当日 `zdf > 3%`（集体上攻要件）。前一日记录的逆势方向若满足三件套即自然通过（升级验证）；**方向判定只认当帧证据，不沿用昨日逆势名单**
4. **标的过心法红线 + 当日层 LLM 两指标不禁止**；标的画像：六池来源、close>MA5（MA5 下行一票否决）、当日 `zdf` 0%~7% 且日内最高涨幅 ≤ 7%（`y1` 极值口径）、资金面硬条件与分时四信号不否决（通用层 §2.2 同强度）

**仓位**：潜在双冰日与双冰确立后首笔均为试错档（≤ 目标 1/2）；**双冰确立后的交易日，当帧回暖 + 三件套确认 → 仓位可放宽至标准档**（不越过重仓档，通用层 §2.5）

## 三、通道 B 出手条件（潜在双冰日尾盘低吸，四项同时，任一缺证据即不出手）

1. **通道资格 + 时点**：`next_day_double_ice_ready == true`，且当前时点在 14:30~14:55
2. **当帧仍冰（主源 = 当帧大盘温度，分层温度纪律）**：当帧 `get_intraday_analysis().temperature_label` ∈ {冰点, 退潮}（全天仍冰、双冰即将确立；当帧大盘标签 ∈ {修复, 升温} 已回暖则机会归通道 A2）；帧缺位 / 当日 LLM 整体缺位 → 无证据 → 不出手
3. **贯穿性主线要件**（与通道 A 第 3 条同款）：标的所属板块近 10 日 ≥3 次进市场前三——尾盘仍冰时无回暖共振可依，**唯一有数据支撑的延续性证据是贯穿性主线**（§六：留存席位 100% 为主线性质）；单日逆势强只记录不出手
4. **标的过心法红线 + 当日层 LLM 两指标不禁止**；标的画像与通道 A 同（六池、close>MA5、买主线强势回踩不买跌幅）

**仓位**：试错档（≤ 目标 1/2）；账户级同时受当日 `position_limit` 约束，取更严

## 四、标的与仓位（三通道通用）

- **标的**：六池选股 + 趋势股画像不变（close>MA5、MA5 下行一票否决——与心法"不抄底"红线一致）；方向选择**只认当帧共振回暖或贯穿性主线**，不买单日逆势强势
- **仓位**：试错档起步；仅"双冰确立后的交易日 + 当帧回暖确认"可放宽至标准档；高潮第 2 日起禁一切新开仓与补足（状态机 gating）

## 五、退出（T+2 验证，刚性条款，三通道通用）

- **T+2 验证**：板块重复上榜 / 标的承接成立 → **加仓与否叠加状态机 gating**：验证日状态机允许开仓（回暖确认期内验证链升级 / 通道 D 资格）→ 按对应通道加仓；不允许（退潮期 / 冰点期 / 高潮第 2 日起——**试错后次日大概率回落退潮期，此为常态**）→ **不加仓、只持有**，去留按通用层止损止盈
- **验证不成 → 离场，不补仓**（样本内 5 个深 ≥2 簇中 2 例为一日游，"不成即离场"是刚性条款）
- 试错后次日直接再冰（嵌套冰点）：按时间止损 / 止损线离场，**不因"已持筹"而放宽**；下一次出手仍需重新满足对应通道的全部条件
- 浮盈持仓的节点先手减仓（`node_exit`，通用层 §3.0——冰点试错仓同样适用）
- 卖出动作不受状态机限制（风控不设时间窗）

## 六、数据锚点（诚实分级）

- 聚簇样本 7 簇、已完结 6 簇 **6/6 在最后一冰日后 2 个交易日内出现 s≥55 反弹**；深度 ≥2 簇 5/5 回升，**但 2 例为一日游**（07-13 簇后 68→32、07-24 簇后 75→30）
- **逆势延续率回放（2026-09-12 统计，支撑"买共振回暖、不买单日逆势"）**：60 日内全部"末冰日（s≤25）→ 次日强回暖（s≥40）"配对 n=9 对，末冰日板块 top3 共 27 席在反弹日 top3 的留存仅 **5 席（19%）**、新面孔 22 席（81%）；5/9 样本完全换血（0/3 留存）；**留存的 5 席全部为贯穿性主线性质**（并购重组 ×3、业绩线、大消费），单日逆势脉冲留存为 0——典型换血案例：07-20 电力煤炭 → 07-21 存储半导体、08-20 创新药出海 → 08-21 业绩线 AI 硬件。局限：小样本（9 对）、板块榜粒度（非个股收益）
- **分层窗口未经个股级回放验证**，全部观察级：每次出手的理由在盯盘总结正文与摘要行操作描述中以前缀 `channel=A` / `channel=A2` / `channel=B` 标注（复盘从 `watch-summary-{date}.md` 汇总统计），**各自累计 ≥8 次后由用户依 T+2 验证成立率审定去留**

## 极端处置（本分册相关）

| 情况 | 处置 |
|------|------|
| 系统性长熊（连冰极深） | 通道不封；严格执行"非当帧共振 / 非贯穿性主线不出手 + 小仓试错"纪律 |
| 共振方向当日全涨停、无可买标的 | 空仓等待，不降低标准买跟风 |
| 共振核心股在交易所重点监管名单 | 降级中军，中军也在名单则放弃本轮 |
| 尾盘买入隔夜黑天鹅 | 止损 / 时间止损照常执行；试错仓封顶损失 |
