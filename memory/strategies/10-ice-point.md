# 战法一：冰点博弈（`ice_point`）

> 适用阶段：**晨起状态文件**为冰点且 **2 ≤ 聚簇深度 ≤ 4**（双冰及以上，含挂起合并簇）。通道资格以预计算 `next_day_channel_open` 为准——深度 <2 未成型、深度 ≥5 长熊防御关闭（极端处置 #1）。通用细则（六池选股 / 止损 / 加速止盈 / 输出规范）见 `memory/dynamic-strategy.md`，本分册只写冰点态特有规则。

## 一、出手窗口（三通道）

冰点试错分三条通道，共享同一资格门槛（晨起冰点 且 2 ≤ 聚簇深度 ≤ 4，即 `next_day_channel_open`）与**同一当日试错预算（三通道合计当日只出手一次**：任一通道已出手 → 其余通道当日不再出手，只做持有管理与 T+2 验证）：

- **通道 A 冰中博弈**：**全天任意时点**（含尾盘段——与通道 B 按当帧温度二选一、不重叠：当帧 ≤25 走 A，回升走 B），**当帧短线温度仍 ≤ 25** 即可出手——买的是"冰点低位的逆势突围强度"，不是"回升确认"；**拉起即停**（当帧短线 > 25 后本通道当日关闭，出手机会归通道 A2 与通道 B）。设计动机：高开低走套人的是"追拉起"，冰中买入位置低、隔夜风险小；冰点环境下的逆势强方向（涨停居前）资金死守意愿强——从冰点拉起的性价比高于追已拉起的盘
- **通道 A2 早盘拉起博弈**：**早盘段 9:36~11:00**（当帧短线温度 **> 25** 已拉起脱离冰位）+ **午后段 11:00~14:30**（拉起后回踩的**水下低吸**档）——买的是"通道开放日已确认的拉起强度 / 拉起后回踩的低位承接"。设计动机：末冰日次日早盘直接强拉是冰簇回升的标准形态（数据锚点：6/6 簇末冰后 2 个交易日内 s≥55 反弹），若只认尾盘认证，全天强势也要等 14:30 高位介入，尾盘温度回落（一日游形态）则通道 B 不成立、整轮簇全程踏空；午后**不追已拉起的高位**（水上 > +3% 不追），但拉起后回踩水下（`zdf` -5%~0% 或分时回踩关键支撑企稳，§0.6）的低吸可出手（对齐通道 C 午后段纪律）
- **通道 B 尾盘认证**：仅 **14:30~14:55**。买的是"全天确认后的回升"——双温度两帧回升 + 突围板块全天验证，过滤早盘冲动与单帧噪声（早盘振幅可达收盘值的 ~90%）

## 二、通道 A 出手条件（四项同时，任一缺证据即不出手）

1. **通道资格**：晨起冰点 且 2 ≤ 簇深 ≤ 4（`next_day_channel_open`）
2. **当帧仍冰**：当帧 `get_intraday_analysis().sentiment_analysis.sentiment_score` ≤ 25（与状态机冰点阈值同值；早盘读数振幅大，本条不判"回升"只判"仍在冰位"——已拉起（>25）后追入即属"追拉起"场景，转通道 A2（11:00 前）/ 通道 B（14:30 后）逻辑）；**帧缺位 / 当日 LLM 整体缺位 → 无证据 → 不出手**
3. **冰中突围要件**（当帧可核验）：方向 ∈ 当帧 `attack_directions` / `attack_sectors` / `emerging_sectors` 名单，**且**该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_daily_stats` 当日行——冰点日资金死守的当帧证据；"回升日居前 2 / 重复上榜"两条留通道 B 全天核验）
4. **标的过心法红线 + 当日层 LLM 两指标不禁止**（四层矩阵 ②③④）；标的画像不变：六池来源、close>MA5，**买逆势强度不买跌幅**（MA5 下行一票否决——与心法"不抄底"红线的一致性保证）

> **证据分级（观察级条款）**：通道 A / A2 均无历史早盘帧数据可回放（早盘 `sentiment_score` 历史序列不存在），未经 56 日重放验证。每次出手的 trade-log `reason` 前缀标注 `channel=A` / `channel=A2`（复盘汇总进当日 `daily-summary`），**各自累计 ≥8 次后由用户依 T+2 验证成立率审定去留**；数据不足期间定位为观察级假设，与衰竭判别式同等待遇。

## 二A、通道 A2 出手条件（拉起博弈，四项同时，任一缺证据即不出手）

1. **通道资格 + 窗口**：晨起冰点 且 2 ≤ 簇深 ≤ 4（`next_day_channel_open`），且当前时点在窗口内（早盘段 9:36~11:00 / 午后段 11:00~14:30；9:36 前当日 LLM 未生成，无证据不出手，总纲 §5.3）
2. **当帧已拉起**：当帧 `get_intraday_analysis().sentiment_analysis.sentiment_score` > 25（≤25 时走通道 A 冰中博弈——两条通道按当帧温度互补覆盖、二选一判定，不叠加）；**帧缺位 / 当日 LLM 整体缺位 → 无证据 → 不出手**；**午后段限水下低吸**（`zdf` -5%~0% 或分时回踩关键支撑企稳，§0.6；水上 > +3% 不追）
3. **拉起强度确认（结构性三件套，防弱反与单票脉冲）**：方向 ∈ 当帧 `attack_directions` / `attack_sectors` / `emerging_sectors` 名单，**且**该板块当日实时涨停数 ≥2 且居全市场前 3（`get_hot_spot_daily_stats` 当日行——资金死守 / 进攻的当帧证据），**且**该板块风向标 `key_stocks` 中 ≥2 只当日 `zdf > 3%`（集体上攻要件）
4. **标的过心法红线 + 当日层 LLM 两指标不禁止**（四层矩阵 ②③④）；标的画像：六池来源、close>MA5（MA5 下行一票否决）、**当日 `zdf` 0%~7% 且日内最高涨幅 ≤ 7%**（`get_stock_minute_trendline` 的 `y1` 极值——7% 高位红线在此取**日内极值口径**：当日曾冲高 >7% 的标的，脉冲回落使"当前 zdf"回到 0~7% 区间也不改变其当日已大涨的事实，一律视为"已拉起的个股"不追。买的是"拉起确认后的板块内低位标的"，不是当日高位标的的回落承接）、资金面硬条件（通用层 §2.2 第 9 条同强度）、分时四信号不否决（通用层 §2.2 第 5 条同强度；`y2` 先入后出形态按通用层 §0.6 / §2.2 第 7 条既有口径判定，不另设门槛）；**reason 记录的资金趋势必须与 `y2` 序列事实一致，禁止拿服务端 `fund_trend` 标签覆盖序列单调性目检**

## 三、通道 B 出手条件（四项同时，任一缺证据即不出手）

1. **聚簇深度 ≥2 且 ≤4**：随通道字段自动满足（状态机预计算）
2. **双温度回升确认（防噪）**：
   - 14:30 后**最近两帧**（约 14:30 / 14:35，盯盘 5 分钟一帧）实时短线温度**均**高于昨日收盘短线温度——当帧取 `get_intraday_analysis().sentiment_analysis.sentiment_score`，昨日收盘 s 取 `regime-state.json` 的 `history` 末条
   - **且**当帧大盘温度 ≥ 昨日收盘大盘温度——当帧取 `temperature_score`，昨日 d 同取 `history` 末条
   - **双温度同向背书**：单温度背离全部是陷阱（08-20 大盘独热 +30 短线没跟、08-21 短线独热 55 大盘退潮，两次背离后均再杀）；大盘温度无日内分时接口（`get_indicator_trendline('temperature')` 为日级序列），背书基准取昨收而非当日日内低点
   - **帧缺位 / 间隔不足 / 昨日 s 或 d 缺值 / 当日 LLM 整体缺位 → 条件②无证据 → 不出手，宁错过**
3. **突围板块满足三条件**：
   - a. 最后一冰当日涨停数 ≥2 且居全市场前 3（冰点日资金死守）
   - b. 回升日涨停数或大肉数居前 2（率先收复）
   - c. 此后重复上榜（过滤单日轮动噪音）
   - 数据源：`get_hot_spot_daily_stats`（按日涨停 / 大肉统计）、`get_top_hot_spots`（当日排名）、`get_hot_spot_rotation --days 10`（重复上榜）
4. **标的过心法红线 + 当日层 LLM 两指标不禁止**（四层矩阵 ②③④，`dynamic-strategy.md` 状态机索引）

## 四、标的与仓位

- **标的**：突围板块内的涨停龙头 / 大肉核心 / 中军，走六池选股 + 趋势股画像不变（**买的是逆势强度，不是跌幅，不构成接飞刀**；MA5 下行标的一律否决——与心法"不抄底"红线的一致性保证）
- **仓位**：试错仓（规模锚：通用层 §2.5 试错档 ≤ 目标 1/2；账户级同时受当日 `position_limit` 约束，取更严；个体级心法红线照常）

## 五、退出（T+2 验证，刚性条款，三通道通用）

- **T+2 验证**：突围板块重复上榜 / 标的承接成立 → **加仓与否叠加状态机 gating**：验证日状态机允许开仓（回暖确认期内验证链升级 / 通道 D 资格）→ 按对应通道加仓；不允许（退潮期 / 冰点期 / 高潮期——高潮期禁新开仓与补足，**试错后次日大概率回落退潮期，此为常态**）→ **不加仓、只持有**，不加仓不构成卖出信号，去留按通用层止损止盈
- **验证不成 → 离场，不补仓**（样本内 5 个深 ≥2 簇中 2 例为一日游，"不成即离场"是刚性条款）
- 试错后次日直接再冰（嵌套冰点）：按时间止损 / 止损线离场，**不因"已持筹"而放宽**；下一次出手仍需重新满足对应通道的全部条件
- 浮盈持仓的节点先手减仓（`node_exit`，通用层 §3.0——冰点试错仓同样适用；注意任意→冰点转弱属 A 条晨起先手触发源）
- 卖出动作不受状态机限制（风控不设时间窗）

## 六、数据锚点（诚实分级）

- 聚簇样本 7 簇、已完结 6 簇 **6/6 在最后一冰日后 2 个交易日内出现 s≥55 反弹**；深度 ≥2 簇 5/5 回升，**但 2 例为一日游**（07-13 簇后 68→32、07-24 簇后 75→30）
- "深度 ≥2 才出手"在样本内无对照组，定位**结构保守性设计（宁错过）**，由进化机制前向验证
- **温度回升 ≠ 可交易性**：突围三条件的完整案例仅 08-24 段 1 个，证据强度弱
- 通道窗口设计（节点先手框架）：A 全天化（尾盘仍冰可出手）；A2 午后水下低吸档（拉起后回踩的低吸机会）；B 窗口 14:30~14:55（与通道 C 统一）——均未经回放验证，观察级统计（trade-log reason 前缀分标 channel=A / A2 / B）

## 极端处置（本分册相关）

| 情况 | 处置 |
|------|------|
| 聚簇深度 ≥5（系统性长熊） | 通道自动关闭（`next_day_channel_open=false`），只观察不出手；旧簇终结、新簇重新 ≥2 才恢复 |
| 突围板块当日全涨停、无可买标的 | 空仓等待，不降低标准买跟风 |
| 突围核心股在交易所重点监管名单 | 降级中军，中军也在名单则放弃本轮 |
| 尾盘买入隔夜黑天鹅 | 止损 / 时间止损照常执行；试错仓封顶损失 |
