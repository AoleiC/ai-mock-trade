# 战法二：情绪主升（`uptrend`）

> 适用阶段：主升状态（连续 2 日 ≥55 后第 3 日确认放行）。入场必然滞后 1~2 根阳线——**刻意设计**：56 日 14 次单日反弹 10 次次日杀回 ≤45（71%），抢跑胜率被数据证伪，双日确认放行 / 拦截记录 3/3 正确。通用细则见 `memory/dynamic-strategy.md`。

## 一、出手窗口与资格

- 盘中全时段（回踩 / 分歧转一致 / 弱转强均合法）
- **当日层 LLM 两指标禁止时当日不出手**（四层矩阵 ② AND 叠加）：当帧 `sentiment_label ∈ {保守, 偏保守}` 且 `alignment == 退潮` → 即使主升态也当日禁开新仓，矛盾记录进 `regime_track` 供进化

## 二、核心买点与仓位非线性

- 核心买点：主线龙头的**分歧转一致**（衰竭性分歧判别见下）/ 缩量回踩企稳 / 次日弱转强承接
- **买点分级 × 仓位成反比**：

| 买点 | 性质 | 仓位 |
|------|------|------|
| 半路（分歧转一致当日） | 激进——买"可能错" | 轻仓试错 |
| 弱转强（分歧日缩量不破关键位 + 次日高开、分时回踩不破均价线） | 中等 | 标准仓 |
| 缩量回踩企稳 | 保守——确认后买"必然贵" | 标准仓偏上 |

- 仓位最高档，仍受 `position_limit` 与单只 30% / 同方向 50% 红线约束；分笔建仓（首笔 ≤ 目标 1/2）照常

## 三、衰竭性分歧判别式（"分歧转一致"的"分歧"必须是衰竭性分歧）

双条件缺一不可：

- **a. 极值已现**（可操作定义）：该指标分时序列创日内最劣值（上涨家数新低 / 主力净额最大流出 / 炸板率新高）**且此后 ≥2 个采样点连续修复**；数据源 `get_indicator_trendline` 的 `szjs` / `zlje` / `zbl` 分时序列；三项中**两项**满足即判"极值已现"
- **b. 回封确认**（极值后率先回封）

反例（09-03 实测）：10:15 / 10:30 两次回封发生在下跌中段（家数仍在下行，未满足 a），事后全失败；13:45 回封发生在 13:37 双极值（家数 1518 / 主力 -170 亿）衰竭后，事后成立。**趋势中段的回封是噪音，极值衰竭后的回封才是信号。**

> 与总纲 §5.1 第 2 条的边界：该禁令禁止的是拿这些指标**自拾为情绪论据**（教训 A.2 语境）；本判别式把它们作为**人审定的买点形态量化要件**（分时接口消费），属策略层合法消费，不得即兴扩展指标集或改判定式。
> 证据强度 n=1 日（观察级）；**前向降级条款：5 次判别中失效 ≥3 次即降级为观察假设**。

## 四、龙头等不到的解法

龙头是**强度指示器**而非唯一标的：龙头不给买点 = 主升确认（筹码锁死），轻易给舒服回踩 = 出货前兆，买点稀缺性本身是信息。可执行窗口：

- a. 方向内中军 / 活跃股的承接（波动窗口比龙头宽）
- b. 弱转强结构区间（不要求买在最低，买在"衰竭将转未转"）

## 五、拐点三步曲（与战法一衔接）

转折日不重仓，**锁定共振最强方向**入观察池；Day 2 方向首次分歧回踩（中军缩量企稳 / 分时承接不破）→ 低吸；确认信号齐备（档位跨档 + 炸板率回归常态 + 龙头晋级不断板）→ 加仓（加仓过状态机层① gating）。

## 六、止盈与代价声明

- 移动止损为主，加速止盈四信号照常（通用层 §0.6）
- 踏空单边行情是本战法的固定成本，空仓是合法操作
- 数据锚点：主升段样本 2 段 3 日（08-06~07、08-27），证据强度弱；不设试运行，靠前向积累与进化
