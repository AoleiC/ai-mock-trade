# 战法二：[短情]高潮期持仓管理（`uptrend`）

> 适用阶段：[短情]高潮期（连续 2 日 ≥55 后第 3 日仍 ≥55 且当日大盘标签 ∈ {修复, 升温} 背书后转入）。**高潮第 1 日（升温惯性延续日，`uptrend_first_day == true`）通道 C / D 视同升温节点照常开放**——转入背书要求当日大盘 ∈ {修复, 升温}，第 1 日必然是双强惯性日；**第 2 日起禁一切新开仓（含通道 A/B/C/D），本分册只管持仓**——脉冲已近尾段（高潮期追入板块 T+1 胜率 67% vs 升温期参与 100%，n=9/6，第 1 日与第 2 日子样本未切分、观察级），追入 = 接均值回归；且体系在高潮期是净卖出方（持仓持续兑现），空仓者第 2 日起买入 = 接自己体系的卖盘。**空仓者第 2 日起的处理**：不参与，等降温期主线回踩窗口（`30` 分册）或新节点——高潮末段的补涨低吸是"末段位"（赔率差、无利润垫拿不住），与通道 C/D 的"节点初段启动位"不是同一种低吸。出手窗口在升温节点与高潮第 1 日（通道 C / 通道 D）；高潮期第 2 日起的任务是**把升温节点建立的仓位管理好、兑现好**。通用细则见 `memory/dynamic-strategy.md`。

## 一、行为总纲

- **禁一切新开仓**：通道 A/B/C/D 在本态全部关闭；补足笔 / 加仓视同新开仓，同样禁止
- **当日层 LLM 两指标**照常监控（四层矩阵 ②）：`偏保守/保守` + `alignment=退潮` 同时出现 → 立即触发环境分层减仓评估（比其他态更严格——高潮期转弱信号就是兑现信号）
- **例外（仅持仓侧）**：持仓的节点先手减仓、止损止盈、撤退清仓不受禁令影响

## 二、持仓管理（本分册核心职责）

- **节点先手减仓的主战场**：
  - 见顶回落预警：`saw_peak_70=true` 且（当帧大盘温度标签 ∈ {降温, 退潮, 冰点}（主源）或当帧短线 < 55（佐证）任一成立）→ 浮盈持仓先手减半仓——**仅高潮期内可触达**（`saw_peak_70` 离开本态即清零），本条是高潮期最重要的单一规则
  - A/B 条（通用层 §3.0，`node_exit`）叠加：阶段转弱晨起先手、温度回落当帧先手（观察级）
- **移动止损为主**，加速止盈四信号照常（通用层 §0.6）——本态加速止盈**最敏感**：高潮末段的放量滞涨 / 长上影 / 板块背离按最严口径执行
- **不抢跑也不拖延**：[板块]一致加速日 T+1 仍有惯性（+1.44%/100%，n=8）——单纯"涨得多"不是减仓理由；触发条件（`saw_peak_70`+回落 / 四信号 / [板块]连强终结）出现才动手，**[板块]连强终结（翻绿 / 跌出前三）→ 48 小时内兑现**（通用层 §3.0 D 条）
- 踏空单边行情是确认期未出手的固定成本，空仓过高潮期是合法操作

## 三、龙头认知（确认期标的选择的传承）

龙头是**强度指示器**而非唯一标的：不给买点 = 筹码锁死；轻易给舒服回踩 = 出货前兆，买点稀缺性本身是信息。方向内中军 / 活跃股的承接（波动窗口比龙头宽）是龙头等不到时的替代——该认知用于回暖确认期通道 C 与通道 D 的标的排序。

## 四、拐点三步曲（前两步在确认期执行，本态只承接第三步的持仓管理）

转折日不重仓，锁定共振最强方向；Day 2 方向首次分歧回踩低吸（确认期通道 C / 通道 D 承担）；确认信号齐备后的持仓管理由本分册 §二 承接。

## 五、数据锚点

- 高潮期板块 T+1 胜率 67% vs 确认期 100%（n=9/6）——高潮第 2 日起禁买的依据（第 1 日为惯性延续日、观察级豁免；60 日历史回放统计，未按高潮期内日序切分子样本）
- 单日反弹次日杀回率 71%（56 日 14 次中 10 次）——双日确认 + 第 3 日转入的设计依据
- 高潮段历史样本 2 段 3 日（08-06~07、08-27），证据强度弱；本分册行为靠前向积累与进化
- 60 日内[短情]高潮期仅 3 日——**本态罕见，体系的日常机会在[板块]通道 D 与确认期通道 C，不在本态**
