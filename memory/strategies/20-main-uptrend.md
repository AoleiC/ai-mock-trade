# 战法二：高潮链持仓管理（高潮 / 连续高潮）

> 适用节点：云端高潮区节点（**高潮** = 当日入高潮区 ≥75，**连续高潮** = 昨日也在高潮区——云端高潮区稀有，60 天回放仅 1 天 ≥75）。**高潮链一律只兑现不加仓**（云端节点 × 操作映射："惯性日只兑现不加仓"——旧"高潮第 1 日可买"特例已取消：高潮区（≥75）是极端过热确认，均值回归风险最高，追入 = 接均值回归；且体系在高潮链是净卖出方（持仓持续兑现），空仓者买入 = 接自己体系的卖盘。**空仓者的处理**：不参与，等高潮降温 / 降温节点的主线回踩窗口（`30` 分册）或新节点——高潮末段的补涨低吸是"末段位"（赔率差、无利润垫拿不住），与通道 C/D 的"节点初段启动位"不是同一种低吸。出手窗口在升温链（通道 C / 通道 D）；高潮链的任务是**把升温节点建立的仓位管理好、兑现好**。通用细则见 `memory/dynamic-strategy.md`。
>
> **节点层与板块层的双层锚定（防误读）**：「惯性最强可买」的实操窗口锚定**板块层**——板块一致加速首日（板块涨停数居全市场前 3 + 风向标集体上攻的首日，盘中可判）由**当时所在节点**的通道承接（冰点链 A2 / 升温链 C/D），**不是等节点跳入高潮区才出手**。云端确认高潮需收盘定格（≥75 满足时板块往往已发酵多日）——若把可买窗口理解为等高潮节点，可买窗口在体系上永远无法兑现。衰竭画像跨路径硬否决与发酵晚段买点约束（核心层「出手节奏与组合纪律」衰竭画像条 / 发酵晚段买点约束条），防止在板块中后段以高位股为载体追一致。

## 一、行为总纲

- **禁一切新开仓**：通道 A/B/C/D 在本节点全部关闭（`realize_only`，云端卖侧基调）；补足笔 / 加仓视同新开仓，同样禁止
- **当日层 LLM 两指标**照常监控（四层矩阵 ②）：`偏保守/保守` + `alignment=双弱` 同时出现 → 立即触发环境分层减仓评估（比其他节点更严格——高潮链转弱信号就是兑现信号）
- **例外（仅持仓侧）**：持仓的节点先手减仓、止损止盈、撤退清仓不受禁令影响

## 二、持仓管理（本分册核心职责）

- **节点先手减仓的主战场**：
  - 见顶回落预警：当帧节点 ∈ {高潮, 连续高潮} 且（当帧 `temperature_level ∈ {冰点, 偏冷}`（结构化主源）或当帧短线温度 < 55（佐证）任一成立）→ 浮盈持仓先手减半仓——**仅高潮链内可触达**（节点离开高潮链即不适用），本条是高潮链最重要的单一规则
  - A/B 条（通用层 §3.0，`node_exit`）叠加：节点转弱晨起先手、温度回落当帧先手（观察级）
- **移动止损为主**，加速止盈四信号照常（通用层 §0.6）——本节点加速止盈**最敏感**：高潮末段的放量滞涨 / 长上影 / 板块背离按最严口径执行
- **不抢跑也不拖延**：[板块]一致加速日 T+1 仍有惯性（+1.44%/100%，n=8）——单纯"涨得多"不是减仓理由；触发条件（高潮链+回落 / 四信号 / [板块]连强终结）出现才动手，**[板块]连强终结（翻绿 / 跌出前三）→ 48 小时内兑现**（通用层 §3.0 D 条）
- 踏空单边行情是升温链未出手的固定成本，空仓过高潮链是合法操作

## 三、龙头认知（升温链标的选择的传承）

龙头是**强度指示器**而非唯一标的：不给买点 = 筹码锁死；轻易给舒服回踩 = 出货前兆，买点稀缺性本身是信息。方向内中军 / 活跃股的承接（波动窗口比龙头宽）是龙头等不到时的替代——该认知用于升温链通道 C 与通道 D 的标的排序。

## 四、拐点三步曲（前两步在升温链执行，本节点只承接第三步的持仓管理）

转折日不重仓，锁定共振最强方向；Day 2 方向首次分歧回踩低吸（升温链通道 C / 通道 D 承担）；确认信号齐备后的持仓管理由本分册 §二 承接。

## 五、数据锚点

- 高潮期板块 T+1 胜率 67% vs 确认期 100%（n=9/6，旧口径 55 确认制回放）——高潮链禁买的依据；云端节点化后高潮区门槛升至 ≥75（更稀有、更极端），禁买依据只增不减（60 日历史回放统计，未按高潮链内日序切分子样本）
- 单日反弹次日杀回率 71%（56 日 14 次中 10 次）——升温链轻仓先手 + 确认后才补足的设计依据
- 高潮段历史样本 2 段 3 日（08-06~07、08-27，旧口径）；云端高潮区（≥75）60 天回放仅 1 天——**本节点极稀有，体系的日常机会在[板块]通道 D 与升温链通道 C，不在本节点**
