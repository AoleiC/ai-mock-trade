# 战法三：高潮降温切换（高潮降温节点）

> 适用节点：云端高潮降温（中区且昨日高潮链——高潮回落未崩；实际市况为"涨停数虚高、资金分散、板块日度轮动"——情绪退潮初段；禁新开仓、允许兑现减仓）。通用细则见 `memory/dynamic-strategy.md`。

## 一、核心认知

此节点**涨停数虚高、资金分散、板块日度轮动**（实测：08-25~09-01 每日领涨换人：创新药→有色→PCB→大农业→业绩线→AI 应用）。**温度优先于涨停数，涨停数不作情绪论据**（07-01 涨停 149 家 / 短线温度仅 48 的背离实例）。

## 二、短线领先观察（降级为观察假设）

"短线温度见顶领先大盘 2~3 日"（08-27 vs 09-01）**仅为观察假设（n=2），不据此单独触发仓位动作**：形态出现时记入复盘总结，样本积累 ≥5 次且方向一致后再评估升级（进化机制）。本态的仓位保护由本分册"加速止盈最敏感 + 禁追 + 只做贯穿主线回踩"承担，不依赖该假设；**与通用层 §3.0 节点先手减仓的关系**：B 条（温度回落当帧先手）与该假设同源不同用法——该假设做**预测**（领先 2~3 日，n=2 不升级），B 条做**已发生回落的应对**（观察级、前向校准），两者不冲突。

## 三、允许

- 只做**贯穿性主线**（10 日内 ≥3 次进 top3，如业绩线样本）的回踩买点
- 昨日强势方向当日企稳后的买点 2/4 参与（买入手册 §0.8 分层节奏保留；盘中按板块企稳信号判定）
- 仓位收敛档
- **本节点不开先手买入通道**（节点先手框架下的刻意保守）：本节点定义即"昨日高潮链、今日回落中区"，处于温度回落节点区——此时拿先手买与节点先手减仓方向相反（回落区接刀），只做贯穿主线回踩的**确认买点**；先手权已在上游节点（升温链通道 C / 冰点链三通道）行使完毕

## 四、禁止

- 追当日领涨板块（单日脉冲 = 轮动噪音）
- 任何形式的半路 / 弱转强（该阶段情绪波动大，形态可靠性下降）
- **`emerging_sectors` 当日不参与**（Day 1 追涨的本质就是追当日领涨，与本条冲突；新冒头方向当日只记录，次日连榜走通道 D——节点 gating 见买入手册 §0.8）

## 五、止盈

四战法中加速止盈最敏感：放量滞涨 / 长上影 / 背离**任一即走**（阈值同通用层 §0.6，执行从严）；**节点先手减仓照常适用**（通用层 §3.0：A 节点转弱晨起先手——本节点的下一站是降温防守，继续回落次日即执行；B 温度回落当帧先手——观察级）——注意见顶回落预警（C 条）仅高潮链内可触达，在本节点**不可触达**，不要引用。

## 六、数据锚点

07-01（涨停 149 / 短线 48 背离）；08-28~09-01（50/60/45 摆动 + 板块轮动）；样本仅 1 段 3 日，证据强度弱。
