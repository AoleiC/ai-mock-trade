## 零、买入侧通用字段消费

### 0.5 资金面硬条件（全部买入路径统一：低吸 / 套利 / 通道 C/D 先手）

买入标的须满足**资金面硬条件**：**当日累计主力净流入 > 0**（资金真实承接 + 活跃度双重确认，心法 §4.3 套利资金面合规红线）。数据取自七池候选集的 `main_amount` / `turn_z`，或 `cli.py market.get_stock_info <code>`。累计净流出的标的不进任何买入评估，**无豁免路径**——个股主力资金分时序列已下线、跨轮差分无数据源（盘中轮禁读 `watch-summary`，总纲 §十一），"资金正在回流"无法量化验证；疑似回流标的等当日累计净额转正后再进评估。

**资金面取数口径（防悬空）**：
- 候选集 `main_amount` 是**格式化字符串**（如 `"2.3亿"` / `"--"`）：判"净流入 > 0"前必须解析数值；`"--"` / 空 / 解析失败 = **无数据**，不得当作任何方向的证据，转用 `get_stock_info` 的 `amount_main`（主力净额，元）
- `amount_main` 再缺位（None / 字段缺失）→ 用 `get_stock_minute_trendline` 的 `y2` 末值（当日主力净额，单位亿）兜底；**三级来源全部缺位 → 按"该字段为空，无法判定"处理，否决买入**（资金承接是硬条件，缺证据 ≠ 通过）

> 注：原 §0.5 末段「盘中实时量能的时段折算」口径已随持仓侧放量滞涨判定迁至**核心层 §0.6 末**（买卖两侧共用）；买入侧换手 / 成交额与全天口径阈值比较同样按该口径折算。

### 0.7 量价持续性判断（买入 / 持有共用）

> 具体术语含义（上涨缩量回踩、持续放量上攻、量价齐升、放量滞涨、放量冲高回落、放量下跌、缩量阴跌）见心法 `memory/trading-mindset.md`「七、术语字典」。本节只规定本账号的**决策用法**与**可执行判定口径**，不重复定义术语本身。

**核心原则**：量价健康是判断题材 / 个股是否仍有持续性的第一指标。买入前必须确认处于"可持续"状态，持有期间若出现"衰竭"信号则加速止盈。

### 健康信号（可持续）—— 决策含义

| 信号 | 决策含义 |
|------|----------|
| **上涨缩量回踩** | 洗盘干净，趋势未坏，可观察低吸 |
| **持续放量上攻** | 资金持续流入，主升健康，可持有或跟随 |
| **量价齐升** | 资金与价格共振，强势信号 |

### 衰竭信号（不可追 / 应止盈）—— 决策含义

| 信号 | 决策含义 |
|------|----------|
| **放量滞涨** | 主力出货，买入否决 / 持有止盈 |
| **放量冲高回落** | 上攻乏力，买入否决 / 持有止盈 |
| **放量下跌** | 抛压重，趋势可能反转，买入否决 / 持有止损 |
| **缩量阴跌** | 无人问津，不是低吸对象 |

### 使用纪律

- **买入侧**：必须满足至少一个健康信号（上涨缩量回踩 / 持续放量上攻 / 量价齐升），且未出现任一衰竭信号。禁止只看方向或涨幅，忽略量价
- **持有侧**：健康信号维持则持有；出现任一衰竭信号，按核心层 §三 加速止盈处理
- **低吸买点**：尤其依赖"上涨缩量回踩"——若回踩时未缩量，或反而放量下跌，说明不是洗盘而是真出货，直接否决
- **判定数据来源**：
  - 日级成交量对比：调 `get_stock_daily_history`（含 `volume` / `ma5_volume` / `ma10_volume`）或 `get_daily_k_data`（含 `volume`）
  - 当日成交额/换手：调 `get_stock_info`（`amount` / `turn_z`）
  - 分时价格与主力：调 `get_stock_minute_trendline`（`y1` 涨跌全序列 / `y2` 仅末位主力净额快照 / `fund_trend` / `fund_divergence` 恒为 null），**该接口无分时成交量字段**，分时"量"需通过日级成交量 / 成交额间接推断

### 0.8 轮动预期差参与（新冒头方向 + 次日观察验证）

> **动机**：方向确认滞后于方向启动 —— 盘面分析把方向升级为"进攻方向"时，核心标的往往已 7%+ 高位或涨停；"全部条件核齐再买"到手的全是接盘位，"等方向走强再买"买到的是后排跟风。轮动节奏与预期差的唯一官方入口：**盘中** `hot_rotation_analysis.emerging_sectors[]`（新冒头方向），参与方式不是放松纪律，而是**用首笔小仓试错换时间上的左侧**。次日机会由通道 D 承接（`40` §二C）；方向连续强势天数的判定见 §2.3 板级历史（服务端历史榜直查）
>
> **状态机 gating（市场层，先于本节一切参与规则）**：**市场节点一票否决（心法 §三）——节点不对，题材再强不买**。**高潮期第 2 日起——禁一切新开仓（含本节所有通道），仅持仓管理**（第 1 日 `uptrend_first_day==true` 视同升温节点，通道 C/D 照常）；**退潮分歧期**——保留昨日强势方向企稳后的买点 2/4 参与（禁追）；**退潮期（非升温第 1 日、非 V 型修复日、非回暖试探日）——禁新开仓，无例外**（V 型修复日 `next_day_v_repair_ready==true` 开放通道 F 盘中先手 + 通道 E 尾盘先手，`40` §二F / §二E；回暖试探日 `next_day_warm_probe_ready==true` 开放通道 G 回暖试探，`40` §二G）；**升温节点（升温第 1 日 `up_count==1` / 回暖确认期 / 高潮第 1 日）**——通道 C（`40` §二A）与通道 D（`40` §二C）适用；**冰点期**——一切盘中开仓统一走战法一分层通道（见 `10-ice-point.md`）：单冰日不操作；潜在双冰日走 B 双冰尾盘低吸（14:30~14:55 当帧无共振方向）或 A2 共振试错（10:00 后当帧有方向过两件套）；双冰确立后的交易日全天通道走 A 冰中试错（当帧无共振方向）或 A2 共振参与（当帧有方向过两件套，通过后放宽仓位）——分流判据为方向两件套，大盘当帧标签不作条件，均叠加四层矩阵 ②③④
>
> **执行节奏（按板块分层，不搞全局时钟一刀切；两类买点见 §二 二元总纲——①题材刚启动跟风、②分歧转一致优先龙头）**：
> - **昨日强势板块（Day 2+：昨日已在进攻名单 / 已发酵方向）→ 今日不急追**：等该板块当日充分释放风险（回踩 / 分歧后**企稳**：板块未从进攻名单消失且 `vs_prev_analysis` 未报降级 + 个股分时回踩关键支撑不破、企稳，核心层 §0.6 分时判读）再按买点 2/4 参与。典型在 10:00 前后完成首波释放，**以企稳信号为准，不机械等时钟、也不得在板块未企稳时抢跑**
> - **新启动方向（Day 1）→ 当日只记录、次日节点许可时走通道 D**：首日进榜胜率 67% 低于连榜 2 日 86%，当日不参与；新冒头方向当日记录板块名与排名，次日若仍居前三**且当日节点许可**（升温节点 / 冰点通道开放日，`40` §二C）按通道 D 尾盘先手参与——节点不对（退潮 / 降温 / 高潮第 2 日起）则继续只记录
> - **午后（13:00~14:30）主做水下低吸**：上午错过 / 盘中分歧回踩的水下票（`zdf` -5%~0%）是下午主战场——买的是"方向仍有预期的水下分歧"，**不追高**（水上 > +3% 下午不再追，§2.2）。**冰点进程内通道 A2 不适用本条**（全时段画像一致，`10` §二A 第 2 条）
> - **两类买点贯穿始终（§二 二元总纲）**：①题材刚启动时买入（买不到龙头可考虑跟风）；②题材分歧转一致时买入（优先龙头 / 最强势股）。其余状态不买：分歧中无转一致证据不抄底、加强段不追高、**再分歧 = 退潮预警**（兑现准备，不参与）
> - 参与优先级：题材刚启动（Day 1）≈ 分歧转一致 > 其余状态（首次分歧观察等待、加强段只持仓不追、再分歧退潮预警不参与）

### 0.8.1 边界（不许越的线）

- **复盘不做推演**（总纲 §7.2）：不产出预期接力方向与次日安排；方向连续强势天数由 §2.3 板级历史盘中直查重建，不依赖任何复盘产物

- **不因"早"豁免任何红线**：不打板、不接力、7% 高位不追、四类股、交易所重点监管名单、撤退方向 0% 照常生效
- `emerging_sectors` 参与只作用于**该新冒头方向本身**，不据此给其它方向分档；`observe_directions` 盘中仍不触发任何买卖（核心层 §0.4）
- **禁止以竞价数据（竞价量 / 竞价委托等）作为任何买卖判定依据**（数据缺失且不准确）；任何盘中参与只用开盘后实时行情（开盘价、分时、主力资金）验证

## 一、选股筛选

### 1.1 候选集（七池合并：趋势三池 + 今日异动拉升池 + 主力净流入榜 + 成交额榜 + 小时热度榜）

**七个来源合并去重**为统一候选集（典型 100~200 只），筛选标准对**所有来源一致**（形态这道门槛照常卡，见下文"两类来源的形态保证不同"）：

| 池 | 调用 | 字段 | 覆盖范围 |
|----|------|------|----------|
| 创业板强趋势 | `get_strategy_trend_stocks 6` | code/name/zdf/price/turn_z/amount/main_amount/value_z_str/intraday/hot_categories | 10 日内涨幅 > 7%，创业板，非 ST |
| 创业+科创大趋势 | `get_strategy_trend_stocks 10` | 同上 | 15 日内 > 9%，涨幅 > 3%，覆盖创业+科创板 |
| 沪深主板强趋势 | `get_strategy_trend_stocks 7` | 同上 | 沪深主板强趋势 |
| 今日异动拉升 | `get_strategy_trend_stocks 4` | 同上 | 当日出现向上类异动（放量上涨 / 急拉 / 放量急拉 / 放量推升，窗口主力净流入 > 0）、排除当日与前日涨停、换手 4%~35%，按异动次数倒序——分钟级实时强势信号，捕捉尚未进趋势池的刚启动标的 |
| 主力净流入榜 | `get_main_inflow_top` | code/name/zdf/main_amount | 主力净流入前 20 |
| 成交额榜 | `get_amount_top` | code/name/zdf/amount/main_amount/turn_z/intraday | 当日成交额前 30 |
| 小时热度榜 | `get_hourly_hot_top` | code/name/zdf/main_amount | 小时热度榜前 30（按热度排名） |

> **两类来源的形态保证不同（核心机制，"筛选标准不变"的落地）**：
> - **趋势三池（6/10/7）**：入库已保证趋势形态（站上 5 日线 + MA5 上移）+ 间距发散 + 股性活跃（接口隐含过滤，标准见 §1.2 接口隐含过滤项）→ 命中即可直接判买点
> - **今日异动拉升池 / 主力净流入榜 / 成交额榜 / 小时热度榜**：**只**保证"当日有向上异动 / 有主力资金关注 / 成交活跃 / 市场热度"，**不保证趋势形态**。这四池是"种子池"，用于捕获**尚未进趋势池**的实时强势 / 突发放量 / 人气聚拢标的（趋势池有入库刷新滞后，异动池是其中时效最快的分钟级信号源）。命中后**必须**用 `get_daily_k_data`（验趋势向上：close > MA5 且 MA5 上移）+ `get_stock_info`（板块归属 / 换手 / up_reason）补验趋势形态，**形态不达标即剔除** —— 这道形态门槛与趋势三池完全一致，只是补验方式不同，**不降低标准**。今日异动拉升池 / 主力净流入榜 / 小时热度榜缺 `turn_z` 等字段时同样用 `get_stock_info` 补齐

**取数方式（七池全拉合并，不存在"主池优先、其余兜底"）**：

- 七个池**全部拉取**，按 `stock_code` 合并去重为统一候选集，**不存在"主池不足才补"的降级逻辑**
- 合并后在统一候选集上做：①剔除撤退方向个股 ②剔除已涨停（不打板）③**今日异动拉升池 / 主力净流入榜 / 成交额榜 / 小时热度榜来源补验趋势形态**（趋势三池跳过，入库已含）④按 §二 判定买点 ⑤结合核心层 §0.2 活跃方向做**仓位权重参考**
- 合并候选集经①~⑤过滤后无可买标的 → 输出"无候选标的"并按核心层 §0.1 两指标联动 + 核心层 §三 止损止盈继续执行（**不**跳过持仓检查，**不**静默空仓）

**约束**：
- 选股池**只来自上述六个接口**。**不**从盘面 `attack_directions` / `attack_sectors.key_stocks` / `get_hot_spot_components` / 连板梯队等任何来源选股
- 候选池**不**做活跃方向归属验证。候选票只要同时满足①不在 `retreat_directions`（已撤退方向，红线 0%）②不在四类股（下跌趋势 / 心电图 / 无题材 / 无放量涨停；趋势三池接口入库隐含过滤，主力净流入榜 / 成交额榜 / 小时热度榜来源命中后随趋势补验一并用 `get_daily_k_data` + `get_stock_info` 核四类）③趋势形态达标（趋势三池入库已含；主力净流入榜 / 成交额榜 / 小时热度榜来源按上文补验）④出现 §二 买点，即可买。**不**要求标的必须落在盘面活跃方向名单内
- **个股取舍由趋势形态 + 买点 + 纪律自主判定，不查盘面活跃方向名单**。盘面活跃方向（方向名）有参考价值，但其下个股名单只是盘面论证方向用的**样本**，**有偏且不完整** —— 形态合格、有买点但不在名单内的标的，同样可以买
- **单只仓位统一上限 ≤ 30%**（心法 §五 仓位红线），具体多少由买点质量、距止损位空间、`risk_warnings` 提示的追高风险**自行研判**：买点位置理想、空间充足给满 30%；尾盘追高、位置偏高则主动收敛，但收敛依据是**位置与风险**，不是**名单归属**（也**不**按来源池分档：趋势三池与主力净流入榜 / 成交额榜 / 小时热度榜来源，仓位上限一致）。目标仓位按 **§2.4 分笔建仓**执行（首笔试错 5% ~ 目标 1/2，§2.5 下限，强确认后补足），不一次性满仓成交
- 龙头是心法层面的优先目标（辨识度最高、带动性最强），龙头无买点时退而求其次做活跃方向内的中军 / 活跃标的
- 趋势三池候选已通过四类股过滤（接口入库隐含完成）；主力净流入榜 / 成交额榜 / 小时热度榜来源命中后随趋势补验一并用 `get_daily_k_data` + `get_stock_info` 核四类股（下跌趋势 MA5 / 分时心电图 / `hot_categories` 无题材 / 日线放量涨停史——全部维度均可数据核验）

**口径说明**：`strategy_id=10` 对应 `app/compute/strategies/strategy_jrqs_dqs.py`（"大趋势"：创业板或科创板、涨幅 > 3%、15 日内 > 9%）。

### 1.2 龙头套利专项（活跃方向内中军 / 活跃股补涨）

> **触发场景**：龙头（板块辨识度最高的标的）已涨停 / 当日涨幅 > 7% 高位 / 错过买点 → 资金溢出到同方向同板块中军 / 活跃股的跟随补涨机会。
>
> **边界红线（方向 / 资金面 / 位置 / 买点类型）见心法 §4.3**。本节是执行层细化 —— 明确四要素联合判定 + 优先级排序，避免把"任何同方向上涨的股"都当成套利。

**四要素联合判定（缺一不可，红线见心法 §4.3）**：

| 要素 | 条件要点 | 验证方式（策略执行层） |
|------|------|----------|
| **① 方向归属** | 同方向同板块 / 主营细分重合 | `get_stock_info` 取 `hot_categories` + `up_reason` 与龙头方向对比 |
| **② 资金面硬条件** | 累计主力净流入 > 0（§0.5，无豁免路径）且 换手 ≥ 5% | 候选集 `main_amount` > 0 且 `get_stock_info` 取 `turn_z` ≥ 5（§0.5） |
| **③ 位置红线** | 当日涨幅 ≤ 7% | 候选股 `zdf` 直接判定 |
| **④ 买点类型** | 分时承接 / 突破超预期买点 | 分时回踩均价线不破后快速拉起 / 放量突破前高（见 §二） |

**优先级排序（与其它候选冲突时）**：

```
低吸区龙头股（当日涨幅 -3% ~ +3% + 龙头）
  > 强势可承接区套利（当日涨幅 3% ~ 7% + 同方向中军 + 资金净流入 + 分时承接 / 突破买点）
  > 跟风股（不评估）
```

**禁止的套利**：
- ❌ 跨方向套利（"AI 算力龙头涨停 → 买半导体方向"等）
- ❌ 资金面流出套利（"主力 -X 亿但我看好"——累计净流出仍买入，§0.5 无豁免路径）
- ❌ 当日涨幅已 > 7% 的位置破红线套利
- ❌ 跟风脉冲套利（"龙头封板带动同板块脉冲 3-5% 但无独立逻辑"）

**判定流程**：
1. **识别龙头**：板块内辨识度最高的标的（不依赖盘面标记）= 当日涨幅最高 + 主力流入最强 + 市值 / 流通市值前列
2. **龙头是否有买点**：当日涨幅 ≤ 7% + 满足 §二 买点之一 → **直接买龙头**（优先级最高）
3. **龙头无买点**（涨停 / 涨幅 > 7% / 错过买点）→ 进入套利评估池
4. **套利评估池筛选**（四要素联合）：①同方向 ②资金面硬条件达标（§0.5：累计净流入 + 换手 ≥ 5%）③涨幅 ≤ 7% ④分时承接 / 突破买点
5. **未命中任一要素** → 输出"无可套利标的"

**接口隐含的过滤项**（候选集入库时已保证，**不重复校验**）：

| 过滤项 | 入库筛选标准 |
|--------|--------------|
| 趋势 | 站上 5 日线（close > MA5）且 MA5 上移 |
| 股性 | 近 120 个交易日内至少 1 次涨停 |
| 形态 | 15 日内阳线多于阴线 + 近 10 日涨幅 > 7% |
| 基本面 | 非 ST、无可转债、自由流通市值 > 30 亿 |

> 候选集由定时任务刷新，存在滞后。盘中若发现候选股临盘异常（突发破位、停牌），用 `get_stock_info` 单票兜底，不维护静态过滤表。

### 1.3 已涨停判定（区分板块）

候选股代码前缀决定涨停板阈值：
- 主板（`60` / `00` 开头）：`zdf ≥ 9.9` → 已涨停（不打板）
- 创业板（`30` 开头）/ 科创板（`68` 开头）：`zdf ≥ 19.9` → 已涨停（不打板）
- 阈值不能统一为 `zdf ≥ 9.9` —— 会误杀创业板 / 科创板 10-19% 的强势未封板股

## 二、买点规则（不打板、不接力、只做超预期）

> 术语定义（首次爆发 / 次日分歧 / 持续发酵 / 健康回踩 / 高位 / 低吸买点等）见心法 `memory/trading-mindset.md`「七、术语字典」。本节为心法的策略落地，只写可执行规则与阈值。

**统一原则**：

**二元买点总纲（一切跟随题材节奏，不固定死；心法 §2.3）**：

题材的典型节奏是状态机：**启动 →（加强）→ 分歧 → 分歧转一致 →（加强）→ 再分歧 = 退潮预警**。分歧不必然转一致（可能直接退潮）；一致加强后的再分歧是退潮开始而非新买点。本战法**只有两类买点**：

1. **题材刚启动时**（Day 1）——**当日不买，次日节点许可时通道 D 参与**：当日只记录观察（买点 5 定义保留于 §2.3 供题材阶段判定），次日板块仍居前三**且当日节点许可**（升温节点 / 冰点通道开放日）时按通道 D 尾盘先手执行（`40` §二C）
2. **题材分歧转一致时买入**（买点 2 / 3 / 4）：题材经历分歧后重新走向一致的时点——**量化要件**（§2.3 事件判定表）：**已经历分歧**（昨日日线收阴 / 收跌 / 冲高回落）**且当日转一致证据**（板块风向标 `key_stocks` ≥ 2 只 `zdf > 3%` 集体上攻 + 个股当日反包：当前价 > 昨日最高 + 板块 ∈ attack 名单判等；`evidence` / `vs_prev_analysis` 等文本仅辅助）。**优先上龙头或最强势的股**（经过分歧换手，龙头辨识度与筹码结构最优）：放量反包突破（买点 3）是转一致的确认形态；分时承接（买点 2）是转一致日的盘中形态；分歧尾声、转一致信号初现时的低吸（买点 4）是窗口 ② 的左侧试错部分

**除此之外一律不买**：分歧中**无转一致证据不预判抄底**（分歧可能直接退潮）；一致加强后的延续段不追高（龙头已辨识，追高易买在加强末端）；**再分歧 = 退潮预警**——不参与，持仓进入兑现准备（核心层 §3.0 环境分层减仓）；退潮途中不抄底。**早盘高开不构成独立买点**：昨日强势板块（Day 2+）早盘不急追，等当日充分释放风险（板块回踩 / 分歧企稳，§0.8 执行节奏）；高开信息只作为回调止跌判定（买点 2 / 4）的**辅助证据**——高开后回踩昨收 / 均价不破企稳 = 承接更强的超预期形态：

- **买点 2（分时承接超预期）**：盘中任何时点都成立；**可用于龙头套利场景**（同方向中军分时回踩均价线不破后快速拉起，伴随成交量持续放大）
- **买点 3（突破超预期）**：盘中任何时点都成立；**可用于龙头套利场景**（同方向中军放量突破前期高点 / 整理平台，成交量 > 近 5 日均量 1.5 倍）
- **买点 4（低吸）**：见 §2.2，适用于首次分歧尾声（窗口 ② 左侧试错）或一致加强段的健康回踩（§2.3 状态机），盘中任何时点都成立
- **买点 5（题材首次爆发追涨）**：见 §2.3，仅适用于题材首次爆发（Day 1）且资金确认阶段，zdf 0% ~ 7%，分时持续放量上攻，不打板

| 优先级 | 买点类型 | 条件 | 适用场景 |
|--------|----------|------|----------|
| 2 | 分时承接超预期 | 开盘后分时回踩不破均价线或前日收盘价，快速拉起，成交量持续放大 | **龙头套利**（同方向中军分时承接）/ 低吸区龙头股 |
| 3 | 突破超预期 | 放量突破前期高点/整理平台，成交量 > 近 5 日均量 1.5 倍 | **龙头套利**（同方向中军突破前高）/ 低吸区龙头股 |
| 4 | 低吸（见 §2.2） | 首次分歧尾声或一致加强段的健康回踩，缩量回踩关键支撑，zdf 范围按阶段区分 | 分歧尾声左侧试错 / 一致加强段收敛参与 |
| 5 | 首次爆发追涨（见 §2.3） | 题材首次爆发（Day 1），资金确认，zdf 0% ~ 7%，持续放量上攻，不打板 | 新题材启动跟随 |

**纪律**（来自心法，不可妥协）：
- 已经涨停 → 不追
- 已经连板 → 不追
- **当日涨幅 > 7%（接近涨停或连板）→ 一律视为高位，不追**（不区分板块；心法 §4.3 套利位置红线）
- **题材首次爆发追涨例外**：Day 1 资金确认阶段，zdf 0% ~ 7% 可追，但禁止打板，且必须满足 §2.3 量价条件
- 错过买点 → 放弃，等下一个
- 买入后立即设止损；不设止损 = 不买入
- **套利标的必须满足 §1.2 四要素联合判定**（方向归属 + 资金面 + 位置 + 买点 2/3）
- **同方向换仓禁止降级**：卖出同方向持仓换入另一标的时，换入标的的辨识度 / 资金面不得弱于换出标的（卖强买弱 = 负向换仓，禁止）——换仓只允许平换或升换；换入端视同新开仓，照常过「出手节奏与组合纪律」全部硬闸（核心层）

### 2.2 低吸买点

**核心定位**：低吸是"**攻击方向内部**的强势股回踩机会"，不是"冷门股抄底"，也不是"高位股追涨"。

**判定条件（正向买入理由 + 前置否决过滤两组）**：

> 第 5、6、7、8、9 条为前置否决过滤：任一条触发即否决买入（第 5 条内部按分级口径——仅放量滞涨 / 长上影触发该条，板块背离为警示不触发），但**不是买入理由，禁止写入买入 reason**；买入 reason 只写第 1~5 条（核心层 §7.1）。

**① 正向买入理由（全部满足）**：
1. **属于近期攻击方向**（命中 `final_analysis.attack_directions[].direction` ∪ `hot_rotation_analysis.attack_sectors[].sector`）
2. **趋势向上**：close > MA5（站上 5 日线）且 MA5 上移；**不要求站上 10 日线**（10 日线仅用于趋势止损，见核心层 §三）
3. **回踩幅度合理**：当前 `zdf` 在 **-5% ~ +3%** 区间；其中首次分歧（Day 2）可放宽至 -5% 水下低吸，多日分歧 / 一致加强段（Day 3+）收紧至 -3% ~ +3%。**不接 -5% 以下的飞刀**（跌幅过深说明承接失效）
4. **板块仍强**：当日盘面进攻方向强度未变弱（`vs_prev_analysis` 未报告该方向降级）
5. **量价健康（§0.7）**：出现**上涨缩量回踩**或**持续放量上攻**或**量价齐升**之一；买入前必须确认未出现放量滞涨 / 放量冲高回落 / 放量下跌 / 缩量阴跌等衰竭信号

**② 前置否决过滤（任一条触发即否决买入；第 5 条内部按分级口径——仅放量滞涨 / 长上影触发该条）**：
5. **分时未现卖点（硬前置，不可跳过）**：买入前**必须**对候选股调 `get_stock_minute_trendline` 采分时（涨跌 `y1` + 主力 `y2`），按核心层 §0.6 判四信号（放量滞涨 / 长上影 / 走势与板块背离 / 资金背离）——**买入侧分级否决**：放量滞涨 / 长上影任一成立即**否决买入**（形态类硬证据、误杀少）；走势与板块背离成立记**警示**（写入候选分析，不否决——主线回踩日个股弱于板块是常态，一票否决误杀合格低吸标的多）；资金背离按核心层 §0.6 现状恒缺位、跳过。持仓侧口径不变（核心层 §0.6 任一成立即加速止盈）。禁用 `zdf` 快照 / K线代替分时判定（教训 A.8，复盘手册附录 A）
6. **资金-涨幅不背离**：主力大额净流入（量级显著，如 > +1 亿）但 `zdf` 压在低位（资金量级与涨幅明显不匹配）→ "钱进价不涨"的派发嫌疑，**优先怀疑派发而非低吸**，需第 5 条分时确认是真回踩还是冲高回落（心法 §4.5）
7. **趋势衰竭 / 非健康回踩**：
   - 若标的满足以下任一画像，视为短线趋势已充分演绎：①近 3 个交易日累计涨幅 ≥ 15%；②近 5 个交易日累计涨幅 ≥ 25%（防"一根阴线洗白"——急涨段被单日回调阴线切出近 3 日窗口的，由本口径兜住）；③近 5 日内出现过累计 ≥ 30% 的急涨段且此后回调未触及 MA5（急涨后高位横盘 / 浅回调同样是末端特征，不因回调阴线出现而解除）；④连续 3 日及以上收阳上涨。此时仅因日内从高位回落到 -5%~+3% 区间，**不再自动视为**"健康回踩"，而更可能是趋势末端的高位震荡 / 早盘资金派发后的余温
   - 买入前必须额外确认：**当前时点正处于当日深度回踩的末端或刚企稳**，即当前价格曾跌破昨日收盘价或 MA5 后获得明显承接，且回拉时伴随缩量或资金回流；若价格已大幅回升（如当前涨幅 > +1% 且已从日内低点反弹超过 2%），则禁止买入。当日"早盘大幅流入"不构成承接加分——主力分时序列已下线，"先入后出"型派发（早盘净流入显著、后段持续回落或转负）叠加衰竭画像（本条第一段任一口径）属派发警报但盘中无法量化验证，衰竭风险由本款反弹幅度要件 + §0.5 累计净流入口径（净流出直接否决）承担
   - **主线趋势核心股不豁免**：最强共振方向内涨幅 / 成交额居前的趋势核心天然更易命中本条——这是设计意图（先手方向转折、不接趋势末端），不是误伤；是否为强主线核心引入"打折豁免"（阈值放宽一档 + 仓位减半，硬指标认定、不认主观），由战法一 §六 观察记录累计 ≥8 例后用户审定，审定前本条对龙头照常执行
8. **题材阶段错配**：不属于 §二 二元总纲任一窗口时**禁止买入**——即不属于窗口 ①（题材启动——当日记录、次日节点许可时通道 D 参与），也不属于窗口 ②（分歧转一致：转一致确认日买点 2/3，或分歧尾声转一致信号初现的买点 4 左侧试错）时，一律不买（其他时候保持谨慎）
   - 若无法明确判定题材阶段 / 事件（§2.3 量化要件），按"无法判定 = 不买"处理（§2.3 防臆想纪律）；拿不准则放弃
9. **资金面硬条件（§0.5 统一口径，教训 A.11）**：买入前**必须**调 `get_stock_info <code>` 取 `amount_main`（主力净额）与 `turn_z`（换手率）。**累计净流出（`amount_main` ≤ 0）= 一票否决（§0.5 无豁免路径）**——资金不承接，不论形态多好、方向多对、买点多理想都不买；换手率 `turn_z` < 5% 说明活跃度不足、资金参与度低，低吸题材股同样否决（盘中判定按核心层 §0.6 末「盘中实时量能的时段折算」口径——10:30 前用 2.5%、14:00 前用 4.5%、14:00 后用 5%）。`amount_main` 缺位时按 §0.5 三级兜底口径取数（候选集 `main_amount` → `amount_main` → 分时 `y2` 末值），全部缺位 = 无法判定 = 不买。**不因"龙头低吸"豁免**；"无背离"（`fund_divergence == "normal"`）**不等于**主力净流入，禁止拿它当资金承接证据

买入 reason 必须显式说明：题材阶段 / 事件（§2.3 状态机：启动 Day 1 / 首次分歧 / 分歧转一致 / 一致加强 / 再分歧退潮，及所属二元窗口）、衰竭判定输入（近 3 日与近 5 日累计涨幅，§2.2 第 7 条口径）、量价信号（上涨缩量回踩 / 持续放量上攻等）、是否处于回踩末端 / 刚企稳、为何判定为真承接而非追高末端——**以上各项均须落到具体数值 / 形态结论，缺任一项 = reason 不完整 = 判定无效（教训 A.14）**。

**下单前门禁（教训 A.14）**：候选选定后、报单前，对**最终选中标的**逐条重跑 ②组全部否决过滤（第 5~9 条，含所属通道的继承边界），每条给出结论与关键数值并写入买入 reason；任一触发即放弃本次出手，不换标的硬凑。否决过滤是"对自己的准入门禁"，不是"筛掉候选名单的工具"——候选遍历阶段跑过不等于终选标的免检；当日以某条款否决过其他标的时，须同口径确认终选标的也过该条。

**成交后落账（硬步骤，跨一切买入路径）**：买入成交后立即调 `cli.py journal.record_decision --action buy`（含 direction 方向归属、成交价量、一句话理由）；否决候选后立即调 `--action veto`（含否决理由——当日复买须推翻此理由，写清关键证据）。机械层每轮对账补录漏记笔只是兜底，不替代主动落账（核心层「出手节奏与组合纪律」第 6 条）。

**时间窗口（按板块分层，§0.8 执行节奏）**：
- **昨日强势板块（Day 2+）早盘不急追**：等该板块当日充分释放风险——回踩 / 分歧后**企稳**（板块未从进攻名单消失、`vs_prev` 未报降级 + 个股分时回踩关键支撑不破、企稳）再按买点 2/4 参与；典型在 10:00 前后完成首波释放，**以企稳信号为准，不机械等时钟，也不得未企稳抢跑**。**禁止以竞价数据（竞价量等）作为任何判定依据**（§0.8.1 数据边界）
- **新启动方向（Day 1）**：当日只记录观察、不买入，次日仍居前三**且节点许可**按通道 D 参与——新方向无昨日获利盘的等待成本已折算进"连榜 2 日"的资格条件；节点不对则继续只记录
- **早盘回踩承接**：10:00-11:30 是 Day 2+ 回踩买点的典型窗口（强势股早盘冲高后回踩均价线 / 前日收盘；早盘高开后回踩不破企稳 = 承接更强的超预期形态，作辅助证据）
- **午后水下低吸（13:00-14:30，主战场）**：上午错过 / 盘中分歧回踩的水下票（`zdf` -5%~0%）——方向仍在当日进攻名单 / 未进撤退名单 + 缩量回踩关键支撑企稳 + 实测资金面硬条件达标（§0.5 口径：累计净流入 > 0）→ 按买点 4 水下低吸；**下午不追高**（水上 > +3% 下午不再追）
- **尾盘 14:30 之后**：非低吸窗口、不追涨；**唯一例外：冰点战法通道与通道 E**（潜在双冰日的通道 B 尾盘冰位低吸——`next_day_double_ice_ready`；双冰确立后的全天试错通道含尾盘段——`next_day_channel_open`；冰点反弹延续日含尾盘段——`next_day_rebound_channel_open`，见 `10-ice-point.md`；V 型修复日的通道 E 尾盘修复先手——`next_day_v_repair_ready`，见 `40-retreat-defense.md` §二E）

**纪律**：
- ❌ "低吸" ≠ 抄底下跌趋势（心法 §4.1：MA5 下行不接飞刀）
- ❌ "低吸" ≠ 在冷门题材 / 无主流资金关注的股上买入
- ❌ 低吸买点出现时不调高单只仓位上限（仍按心法 §五 ≤ 30%）

### 2.3 题材阶段判定与买点匹配

> 本条是心法 §2.3「题材生命周期与持续性纪律」的策略落地。术语定义（首次爆发 / 次日分歧 / 持续发酵 / 健康回踩）见心法 `memory/trading-mindset.md`「七、术语字典」。任何买入必须先回答"题材当前处于哪个阶段 / 事件（二元总纲的窗口 ① 还是窗口 ②）"，**不能拿一个买点套所有阶段**。

#### 题材阶段判定（状态机：启动 →〔加强〕→ 分歧 → 分歧转一致 →〔加强〕→ 再分歧退潮）

> **防臆想硬纪律**：阶段判定以**量化主证**为准（数值字段计数 / 日线 bar 判等 / 名单判等 / 服务端历史榜判等）；`evidence` / `signal` / `watch_reason` / `vs_prev_analysis` / `action_advice` 是 **LLM 自由文本，一律只作辅助**——与量化结论同向时增强信心，**量化要件缺失时不得单独触发任何买卖**（无法判定 = 不买，宁错过不臆想）。

**量化主证（三条腿）**：

1. **个股日线**：调 `get_stock_daily_history <code>` / `get_daily_k_data <code>` 取近 5 日 bar（open / high / close）：
   - **起爆资格**：近 3 日累计涨幅 < 15% 且近 5 日累计涨幅 < 25% 且非连续 3 日收阳（口径与 §2.2 第 7 条衰竭判定同源，防急涨标被单日阴线洗成"新启动"；区分"新启动"与"旧题材延续"，后者不是窗口 ①）
   - **分歧证据**：昨日 bar 收阴 / 收跌（close < 前日 close）/ 冲高回落（昨日 high − close ≥ 4%）之一
   - **反包证据**：当日当前价（`get_stock_info` 实时 / `get_stock_minute_trendline` 末值）**> 昨日 bar 最高价**
2. **板块风向标计数**：当帧 `attack_sectors[]` / `emerging_sectors[]` 中该板块 `key_stocks[].zdf`（代码查表填充的数值，非 LLM 输出）逐只计数：
   - **集体上攻**：≥ 2 只 `zdf > 3%`（或半数以上 > 0 且最高者 > 5%）
   - **分化**：涨跌互现且 > 3% 者最多 1 只
   - **集体走弱**：半数以上 `zdf < 0`
   - 板块强度辅助：`today_zt ≥ 3` 或 `today_inflow` 显著为正（可选字段，**缺位时跳过，用 key_stocks 计数兜底**）
3. **板级历史（服务端历史榜直查）**：该方向"此前已连续强势 N 日"由服务端历史热度榜当场重建——从 `market.get_daily_indicators_history --days 10` 的 `dates` 取最近 2~3 个已完成交易日，逐日调 `market.get_top_hot_spots --date <日期> --limit 3`，判定板块名是否连续居市场前三（口径与通道 D 连榜判定同源，`40` §二C）。任一接口失败 / 数据缺位 → 视为无法确认"此前强势"，再分歧预警判定降级为普通分歧处理（不误判退潮、也不臆想强势）

**事件判定（量化要件组合）**：

| 事件 | 量化要件（须同时成立） | 文本辅助（不单独构成） |
|------|------------------------|------------------------|
| **启动（Day 1）** | 个股起爆资格 + 板块风向标集体上攻 | evidence / signal 语义"今日首次""新晋方向"；vs_prev 未报告该方向此前已在进攻名单（启动事件仍判定——供通道 D 次日连榜资格追踪） |
| **首次分歧** | 个股分歧证据（昨日日线）+ 板块风向标当日分化（或该板块从 attack 名单降入 observe / 名次明显下滑） | vs_prev 语义"分化 / 走弱"；evidence 强度描述转弱 |
| **分歧转一致** | **已经历分歧**（个股昨日日线分歧证据）+ **当日转一致证据**：板块风向标集体上攻 **且** 个股当日反包（当前价 > 昨日最高）**且** 板块 ∈ 当日 attack 名单（判等） | evidence / vs_prev 语义"反包 / 集体走强 / 分歧转一致" |
| **再分歧（退潮预警）** | 板级历史直查确认该方向此前已连续居市场前三 ≥ 2 日 + 当日板块风向标集体走弱 **或** 板块从 attack 名单消失 | vs_prev 语义"走弱 / 降级 / 逆转"（核心层 §3.0 已有触发源，同向增强） |

> **数据限制**：任一量化要件字段缺位（如 key_stocks 为空、日线接口失败）→ 该事件**无法判定 → 不买**，不降标准、不用文本顶替。`today_zt` / `today_inflow` 为可选字段，缺位时跳过该选项，不减低其它要件标准。

#### 阶段与买点匹配（二元总纲的落地）

| 阶段 / 事件 | 判定特征（量化要件，见上方"事件判定"表） | 可用买点 | 涨幅区间 | 仓位态度 |
|------|----------|----------|----------|----------|
| **启动（Day 1）** | 个股起爆资格（近 3 日未明显上涨）+ 板块风向标集体上攻 | **当日不买**——次日板块仍居市场前三**且节点许可**按通道 D 尾盘先手（`40` §二C） | —（次日按通道 D 标的画像 0%~7% 未涨停） | 次日通道 D 试错档，禁止打板；节点不对继续只记录 |
| **首次分歧（Day 2，或任意日首次分化）** | 个股昨日日线分歧证据 + 板块风向标当日分化 | **观察等待为主**；仅分歧尾声 + 转一致信号初现（个股率先反包承接）→ **买点 4 左侧试错** | -5% ~ +3%（多日分歧后收紧至 -3% ~ +3%） | 试错仓，**禁止无转一致证据的预判抄底**（分歧可能直接退潮） |
| **分歧转一致（事件，任意日）** | 已经历分歧 + 板块风向标集体上攻 + 个股当日反包（当前价 > 昨日最高）+ 板块 ∈ attack 名单 | **买点 2 / 3，优先龙头或最强势股**（分歧换手后龙头辨识与筹码最优） | 按个股反包 / 突破位判定 | 窗口 ② 主仓位，确认后按 §2.4 补足 |
| **一致加强（转一致后的延续段，Day 3+）** | 板块连续居市场前三 ≥ 2 日 + 当帧风向标集体走强 | **只持仓不追高**——龙头已辨识，追高易买在加强末端；仅回踩清晰且转一致逻辑仍在时可按买点 4 收敛参与 | -3% ~ +3% | 仓位收敛，没有清晰回踩则放弃 |
| **再分歧 = 退潮预警** | 板级历史直查确认此前已连续居市场前三 ≥ 2 日 + 当日板块风向标集体走弱或从 attack 名单消失 | **禁止买入**；持仓进入兑现准备 | — | 核心层 §3.0 环境分层减仓 |
| **退潮** | 进撤退名单 / vs_prev 报告退潮 | **红线 0%** | — | 清仓（核心层 §0.2） |

#### 执行纪律

- **分歧不必然转一致**：首次分歧后必须等**转一致证据**出现才参与（窗口 ②），无证据的分歧中预判抄底 = 接飞刀（心法 §4.1）
- **一致加强后的再分歧 = 退潮开始**，不是第二个回调买点——不参与，持仓兑现准备；轮动的正确参与是等**下一个题材启动**（窗口 ①）或**下一个方向的分歧转一致**（窗口 ②），不在退潮题材里反复抄底
- **不能拿 Day 2 的低吸规则去做 Day 3+ 的票**：Day 3+ 必须有更清晰的缩量回踩或持续放量上攻，否则放弃
- **不能拿 Day 1 的追涨规则去做 Day 2+ 的票**：Day 2+ 还从 0% 以上追涨，属于追高，除非回到当日回踩末端
- **买入 reason 必须写明阶段 / 事件**："题材启动跟风（Day 1）"、"分歧转一致（窗口 ②，含转一致证据）"或"分歧尾声左侧试错（窗口 ② 左侧）"，并给出判定依据
- **其他时候保持谨慎**：不属于窗口 ① / ② 且量价不健康的，一律不评估、不买入

### 2.4 分笔建仓（试错 + 确认补足）

> **动机**：低吸区优先级最高，但"全部条件确认后才买"会把成交点推高到强势区（确认成本右移——条件核齐时价格已走）。分笔结构用**首笔试错对冲晚确认**：初部确认即小仓进场，强确认再补足，买点自然左移；T+1 当日不可卖，首笔减半即单笔风险减半。通道 D 的首笔同款结构（连榜 2 日资格 + 尾盘先手）。
>
> **状态机 gating**：**补足笔视同新开仓过层①**（核心层状态机索引四层矩阵）——补足时点市场层不允许开仓（防守 / 预备）→ 不补足、只持有（不加仓不构成卖出信号，去留按核心层 §三 止损止盈）；**冰点态量化放宽：强确认出现时可补足，单只累计 ≤ 15%（试错档封顶 = 目标 1/2），无强确认仍不补**；卖出动作不受状态机限制。

**执行规则**：

| 阶段 | 触发条件 | 仓位动作 |
|------|----------|----------|
| **首笔试错（低吸）** | §2.2 ①组**全部达成**（五条静态条件：方向 / 趋势 / 回踩幅度 / 板块仍强 / 量价健康——回踩发生中即可核验，**不要求**买点 2/3 的动态拉起 / 突破确认），且资金面硬条件（§0.5 口径：累计净流入 + 换手 ≥ 5%）达标、分时四信号否决（第 5 条）通过、②组前置否决全部不成立 | 建首笔 ≤ 目标仓位的 **1/2**，立即设止损 |
| **首笔试错（通道 D 板块连强）** | [板块]连续 ≥2 日居前三（`40` §二C 资格）+ 候选 `zdf` 0%~7% 未涨停 + 资金面硬条件（§2.2 第 9 条）达标 + 分时四信号否决（第 5 条）通过 + 量价健康（§0.7） | 建首笔 ≤ 目标仓位的 **1/2**（[短情]退潮/冰点日折半），立即设止损 |
| **建仓（分歧转一致确认，窗口 ② 右侧）** | §2.3 分歧转一致**量化要件全部成立**（昨日分歧证据 + 当日风向标集体上攻 + 个股反包当前价 > 昨日最高 + 板块 ∈ attack 名单），买点 2 / 3 本身即为强确认，优先龙头或最强势股 | 买点 2/3 已是强确认，可按目标仓位一次建足（合计 ≤ 30% 心法红线），立即设止损；资金面硬条件（§2.2 第 9 条）与分时四信号否决（第 5 条）照常执行 |
| **确认补足** | 下列任一强确认出现：放量突破前高 / 整理平台（买点 3）；分时回踩不破均价快速拉起 + 主力持续流入（买点 2）；持续放量上攻 / 量价齐升延续（§0.7） | 补足至目标仓位（合计仍 ≤ 30% 心法红线） |
| **确认不现** | 当日未出现任一强确认 | 试错仓按核心层 §三 个股级纪律独立处理，**禁止摊低成本式加仓** |

**纪律**：
- 首笔与补足共享同一目标仓位预算；试错仓触及固定止损 → 止损离场，不等确认信号
- **不因分笔降低任何一道过滤**：四信号否决、资金面硬条件、趋势衰竭过滤（§2.2 ②组）在首笔前全部照常执行
- 补足笔的买入 reason 单独记录确认信号（核心层 §7.1 买卖 reason 不混写）

### 2.5 仓位阶梯与加重时点约束（跨战法通用）

> **动机**：先手通道（A/A2/B/C）只解决"进场时点"，都是轻仓；"什么时候上重仓 / 加仓"的约束此前分散在 §2.4 / 冰点 §五 / 战法二 §五 三处，本节集中为唯一权威表述。**一句话：先手可以左侧，加重必须右侧。** 先手仓的真正价值是重仓的建仓成本压缩器——确认日只需补足差额，实际均价低于放行日从零追入。

**三档阶梯（单只口径；天花板三维取最严：单只 30% / 同方向 50% / 当日 `position_limit`）**：

| 档位 | 规模锚 | 资格条件 |
|------|--------|----------|
| **试错仓（先手档）** | **5% ~ 目标仓位的 1/2**（总资产口径；目标受单只 30% 约束 → 区间 **5% ~ 15%**） | 四层矩阵通过 + 所属阶段通道认证（冰点 A/A2/B、升温节点 C、主升半路买点）——买的是"可能对" |
| **标准仓** | 目标仓位的 1/2 → 全额 | 主升 / 震荡态 + 中档买点（弱转强 / 缩量回踩企稳 / T+2 验证成立 / §2.3 分歧转一致确认） |
| **重仓（满配档）** | 目标全额（单只 ≤30%） | **三重确认齐备**：① 确认期验证链（通道 C/D 试错笔存续且每一步验证通过——温度不回落、板块不退榜；**高潮第 2 日起禁新开仓与补足，重仓只可能发生在升温节点内（含高潮第 1 日）**）② 最保守买点（缩量回踩企稳——"确认后买必然贵"，贵是重仓的入场费）③ 环境健康（`alignment=共振` 且方向在 `attack_directions`） |

**试错仓下限防呆（单笔试错至少 5%——0.56% 级微仓佣金摩擦占比过高、盈亏验证无参考价值，"还不如不买"）**：

- 下限 **5%（占总资产）** 对全部先手试错通道统一生效（A / A2 / B / C / D / E / F）；通道内更细上限约束（冰点折半 7.5%、通道 E 单只 ≤10%、通道 F 单只固定 5%）保留，但区间两端取交后**上限不得低于 5%**
- 当日 `position_limit` 剩余空间（limit% − 当前持仓%）< 5% → **不出手**（账户层已不允许有意义的试错仓位，微仓凑单禁止）
- A 股整手约束：按整手取值不低于 5%；一手即超区间上限的标的（高价股）该档不可选，放弃不硬凑

**加重时点约束（加仓 / 补足全部视同新开仓过层①）**：

- 分笔补足（§2.4）：防守 / 预备**不补足、只持有**（不加仓不构成卖出信号）；**冰点态量化放宽——强确认（§2.4 三种之一）出现可补足，单只累计 ≤ 15%（试错档封顶）**、账户级仍受当日 `position_limit` 约束，无强确认仍不补（防摊平）
- T+2 验证加仓（冰点 §五）：验证成立**且状态机已放行**（主升 / 震荡）才加
- 拐点三步曲（战法二 §五）：确认信号齐备（档位跨档 + 炸板率回归 + 龙头不断板）后加
- **环境转弱（核心层 §3.0 任一触发）期间禁止一切加重**（只减不加）；止盈松紧跟随环境（核心层 §3.0 对称面）自动收紧
