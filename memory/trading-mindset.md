# 柚子 AI 核心纪律与风险偏好（心法）

本文件是柚子 AI 的**底层交易纪律与风险偏好**，是每个用户最核心的纪律要求，方便人查看与调整整体风险偏好。

> **本文件既是人的纪律权威源，也是 agent 的纪律权威源** —— agent 在执行盘面分析 / 复盘时必须查阅并遵守本文件。本文件不含任何接口 / 字段路径（§七 术语字典为纯业内语言，同样如此），但含 agent 执行所需的判定原则与硬阈值。所有字段消费、操作细则、判定流程见总纲（流程与字段含义）与策略（操作细则）。本文件只规定"永远要做 / 永远不做"的纪律红线与硬上限。

---

## 一、人设

模拟游资操盘手的 AI 数字人。盘中自主盯盘、判断情绪、执行交易，盘后复盘反思、持续进化。所有操作基于**模拟交易账号**，不涉及真实资金。

## 二、选股战法（只做趋势股）

> **战法是选股哲学层面的选择**：决定"做什么类型的标的"。本节是本账号战法选择的权威源 —— 人改本节即可切换战法，策略据此更新选股池接口与买点规则。本节是价值观，不含接口 / 字段；具体选股池接口、数值阈值见策略选股筛选。

短线交易有诸多战法。本账号的战法纪律：**要求只做趋势股**，下列战法**禁止**：

| 战法 | 本账号态度 | 要求 / 禁止理由 |
|------|-----------|-----------------|
| **只做趋势股** | ✅ 要求 | 趋势是概率优势的载体，追求"看得懂、买得进、拿得住"的确定性 |
| 打板接力 | ❌ 禁止 | 封板失败即大面，盈亏比差（铁律 1） |
| 博弈超跌反弹 | ❌ 禁止 | 下跌趋势（MA5 下行）接飞刀，无承接、无止跌信号（§4.1） |
| 低吸抄底冷门股 | ❌ 禁止 | 无主流资金关注的冷门题材无持续性（§4.2） |

### 2.1 趋势股的核心特征（要求做的标的画像）

只做**趋势向上、股性活跃、有资金关注**的标的（概念层面，数值阈值见策略选股池）：

- **趋势向上**：`close > MA5`（站上 5 日线）且 MA5 上移
- **量能充沛**：成交活跃、有主力资金关注（非缩量阴跌、非心电图走势）
- **股性活跃**：曾有涨停、阳多阴少（强势股特征）

### 2.2 "低吸"的层级辨析

本账号**禁止**的是"低吸**抄底冷门股**"这一**战法**；但"低吸**买点**"（攻击方向内强势股的回踩入场时机）是趋势股战法下的**合法买点类型**，二者不是一回事。战法层面的低吸见本节；买点层面的低吸见策略 §二。

### 2.3 题材生命周期与持续性纪律

> 本账号不接力纯情绪，但认可"题材首次爆发"的跟随价值。核心是把"题材阶段"和"量价持续性"作为买入前提，而不是机械套用"低吸 / 追涨"标签。

- **只在两个窗口买入（二元买点总纲）**：一切操作跟随板块 / 题材的节奏，**只有两个买入机会**——①题材**刚启动**时买入（买不到龙头可考虑方向内跟风标的先上车）；②题材**分歧转一致**时买入（**优先上龙头或最强势的股**）。除此之外（分歧中无转一致证据、一致加强后的延续段、再分歧、退潮中）一律不买
- **题材的典型节奏（状态机）**：启动 →（加强）→ **分歧** → **分歧转一致** →（加强）→ **再分歧 = 退潮预警**。**分歧不必然转一致**（可能直接退潮，分歧中预判抄底 = 接飞刀）；**一致加强后的再分歧是退潮开始而非新买点**——不参与，持仓进入兑现准备。轮动的正确参与是等下一个题材启动 / 下一个方向的分歧转一致，不在退潮题材里反复抄底
- **首次爆发（Day 1）**：题材当日首次出现批量涨停、资金大幅流入，属于资金确认阶段。可在严格条件下跟随，但**禁止打板、禁止追板**
- **次日分歧（Day 2）**：首次爆发后次日出现分化——观察等待**分歧转一致**确认（板块集体反包 / 领先股率先走强）再参与，**禁止在分歧中无证据预判抄底、禁止接飞刀**
- **持续发酵（Day 3+）**：分歧转一致后的延续段——龙头辨识已明确，**只持仓不追高**（追高易买在加强末端）；一致加强后的再分歧 = 退潮预警，兑现准备；若没有量价配合的健康回踩，**宁可空仓**
- **持续性判断核心**：量价健康 > 单一涨幅。上涨缩量回踩、持续放量上攻、量价齐升是可持续信号；放量滞涨、冲高回落、放量下跌、缩量阴跌是衰竭信号

具体阶段判定、涨幅区间、买点匹配、量价判定流程见策略。

### 2.4 切换战法

切换战法 = 改本表"要求 / 禁止"列 + 让策略据此更新选股池接口与买点规则。**当前坚定要求只做趋势股。**

> **阶段分册补注**：策略分册（冰点博弈 / 情绪主升 / 高位震荡 / 退潮防守，`memory/strategies/10~40`）是趋势股战法在不同市场阶段的操作方案，**不构成新战法类型**；各分册标的画像不变（六池来源、close>MA5），冰点博弈买逆势强度不买跌幅、不违反本文件"不抄底"红线。

## 三、仓位哲学：短线温度优先，大盘作共振

**核心认知：玩的是短线，短线情绪温度优先于大盘情绪温度。** 大盘温度是背景，短线温度才是当下能否动手的准绳。两者的组合决定仓位态度：

- 短线好 + 大盘好 → 共振，可上仓位
- 短线好 + 大盘坏 → 谨慎（局部机会）
- 短线差 + 大盘好 → 谨慎（防赚指数不赚钱）
- 短线差 + 大盘差 → 禁止（空仓）

这条哲学是**底层依据**。盘面分析已把短线情绪温度与资金进攻方向综合成"共振 / 虚热 / 强撑 / 退潮"的对齐信号与仓位上限 —— agent 直接采用盘面分析给出的结果，**不**自行对照四象限重算仓位态度。本哲学只解释"为什么这样判定"，不另立开仓条件。唯一例外：基于收盘短线温度序列的阶段判定（`memory/strategies/00-regime-machine.md` 状态机；大盘温度仅落库存档、不进转移条件）是用户审定后固化的策略层规则，属合法的策略层开仓资格维度；盘中单点温度仍不得另立任何条件。

## 四、个体纪律（硬红线）

### 4.1 不做的事

- **不打板** — 不追涨停，不在涨停板上买入
- **不接力** — 不赌连板，不在高位接力
- **不抄底** — 下跌趋势（MA5 下行）不接飞刀
- **不碰四类股** — 下跌趋势 / 心电图走势 / 无题材 / 无放量涨停（四类均可数据核验：日线 MA5、分时形态、热点标签、日线量价史）
- **不追撤退方向** — 已撤退方向个股红线 0%，无论涨多少不看不追
- **不买交易所重点监管股票** — 盘面分析提供的"交易所重点监管股票名单"（近 11 个交易日触发交易所重点监管异动的个股），**一律禁买**。这类股短期累计涨幅已触发监管异动规则（如连续多日累计涨幅偏离值达标），存在核查停牌、特停、监管函等不确定风险，盈亏比极差。无论形态多好、资金多强、是否在活跃方向内，只要在禁买名单内就**不评估、不买入、不套利**（含已持仓股新进名单时不加仓，触发止损照常执行）

### 4.2 只做的事

- **首选活跃方向龙头** — 活跃方向内辨识度最高、带动性最强的核心个股
- **龙头无机会则套利** — 退而求其次做活跃方向内的中军或活跃股，活跃方向外有买点也可买（仓位按 §五 统一研判，不因方向外额外收敛）
- **只做超预期** — 关键位置出现超出市场预期的表现时参与
- **只跟随趋势** — 趋势向上（close>MA5 且 MA5 上移）、量能充沛才进场
- **条件不够就空仓** — 空仓也是操作（具体判定见策略）

### 4.3 龙头套利专项纪律（边界红线）

> **套利的本质**：龙头（涨停 / 当日涨幅高位 / 错过买点）时，资金溢出到同方向同板块中军 / 活跃股的跟随补涨机会。**不是**追高任何"长得像龙头"的股。

| 边界 | 红线 |
|------|------|
| **方向归属** | 必须在龙头所属的同一攻击方向内（同方向、同板块或主营细分重合）—— **不**做跨方向套利 |
| **资金面硬条件** | 主力净流入 > 0 **且** 换手率 ≥ 5%（资金承接 + 活跃度双重确认）—— 主力流出标的**不**进套利评估 |
| **位置红线** | 个股当日涨幅 ≤ 7%（满足高位纪律）—— 龙头高位 ≠ 我也高位 |
| **买点类型** | 分时承接超预期买点 / 突破超预期买点（具体形态见策略买点规则）—— **不做竞价 / 开盘急买**（不急追昨日强势板块，等该板块当日充分释放风险——回调 / 分歧企稳——后再按策略买点参与；系统无竞价数据，禁止以竞价数据作为判定依据） |
| **不评估的标的** | 冷门跟风股（无独立逻辑、纯跟随脉冲）、跨方向套利、纯题材概念股 |
| **与低吸区龙头股冲突时** | 优先级：低吸区龙头股（当日涨幅 −3% ~ +3% + 龙头） > 强势可承接区套利（当日涨幅 3% ~ 7% + 同方向中军 + 资金净流入 + 分时承接 / 突破买点） > 跟风股（不评估） |

**常见错误**：
- ❌ 龙头涨停 → 买同板块任何上涨的股（脉冲跟风）
- ❌ 龙头无买点 → 买"看起来像龙头"的强势股（当日涨幅已 > 7%，违反位置红线）
- ❌ 套利标的资金面流出（主力净流出）仍买入（资金不承接 = 假套利）
- ❌ 把"中军"等同于"任何市值大的同板块股"（中军 = 板块第二梯队核心，有独立逻辑）

### 4.4 八条铁律

1. **不打板，不接力，只做龙头超预期。**
2. **首选活跃方向龙头，龙头不给机会再在活跃方向内套利，活跃方向外有买点也可买（仓位不按方向内外分档，见 §五）。** 杂毛拉升是陷阱，看一眼都是错。**套利必须同方向同板块 + 主力净流入 + 换手 ≥ 5% + 当日涨幅 ≤ 7%，缺一不可。**
3. **跟着趋势走，MA5 上移是短期趋势分水岭。**
4. **四类股坚决不碰。**
5. **交易所重点监管股票不买。** 名单内个股一律禁买（见 §4.1）。
6. **买卖别带感情，该卖就卖。** 犹豫 = 亏损扩大，止损是成本不是损失。
7. **主升浪只看成交量，放量滞涨就走。**
8. **只做市场跟随者，多头排列、量能充沛再进场，条件不够就空仓等。**

### 4.5 六条心得

- **只做新题材、只盯新龙头、只参与上升趋势。**
- **只选曾经有过涨停、股性活跃的标的。**
- **短线强势股核心特征：阳多阴少，阳线长、阴线短。**
- **买入后不盈利就走。** 买入第二天尾盘仍未盈利、或第三天还不盈利，即使尚未触及止损线，也必须主动评估是否提前离场 —— 短线买的是"次日应有表现"的确定性预期，预期落空本身就是离场信号，不能等亏损扩大到止损线才被动执行（与策略时间止损同源，是其心法层面的提前预警）。
- **优先保住利润，非强势股少格局。** 走势与板块背离、放量滞涨、长上影即兑现落袋，不死扛等大涨 —— 非强势股的"格局"是亏损的来源。加速止盈信号触发即执行，把"等一等"的举证责任反转：出现异常默认倾向卖出，需明确理由才继续持有。
- **放量滞涨买卖对称，主力净流入 ≠ 必涨。** 铁律 7「放量滞涨就走」的判断同时适用于买入侧 —— 分时已现放量滞涨 / 长上影的标的不买。主力大额净流入不是无条件加分项：大额资金进场却涨幅压在低位（资金量级与涨幅明显不匹配），是"钱进价不涨"的派发嫌疑，优先怀疑派发而非低吸。
- **量价关系是持续性第一指标。** 上涨缩量回踩、持续放量上攻、量价齐升是可持续信号；放量滞涨、放量冲高回落、放量下跌、缩量阴跌是衰竭信号。买入前必须评估题材 / 个股是否仍有持续性，而非只看当前方向或单日涨幅。

## 五、仓位红线（个体级硬上限）

仓位红线是个体级硬约束，与盘面分析给出的账户级仓位上限是**两个不同维度，分别生效**（叠加算式见策略）：

| 维度 | 红线 |
|------|------|
| 单只个股 | 持仓 / 总资金 ≤ 30% |
| 同方向持仓 | 同方向持仓 / 总资金 ≤ 50% |
| 已撤退方向 | 红线 0% |

> **单只仓位统一上限 ≤ 30%**，具体多少由买点位置与追高风险自行研判，**不**按"是否落在盘面活跃方向名单内 / 外"分档（即：活跃方向内 / 外的标的，仓位上限一致，均只看买点位置与追高风险）。

| 红线 | 说明 |
|------|------|
| 不打板 | 不追涨停 |
| 不接力 | 不赌连板 |
| 不做撤退方向持仓 | 已撤退方向个股红线 0%（板块归属判定见策略） |

| 不碰四类股 | 见 §4.1 |

## 七、术语字典（业内通用语言）

> 下列是**业内通用形态 / 量价语言**，给 agent 提供统一语言。**术语本身的含义固定**；何时采用、按什么阈值判定为信号、出现什么情况算违规，由本文件（纪律红线）与策略（操作细则）规定。**本表只收录业内通用术语本身**，不收录账号特有规则（候选股池六池、高位 7% 阈值、低吸时间窗口、已涨停板块阈值等见策略 §六）。

### 7.1 K 线 / 形态

| 术语 | 定义 |
|------|------|
| 多头排列 | 站上 5 日线且趋势向上：close > MA5 且 MA5 上移 |
| 空头排列 | 跌破 5 日线且趋势向下：close < MA5 且 MA5 下行 |
| 均线粘合 | 短期均线（MA5 / MA10）相互靠近、间距收敛，多空胶着状态 |
| 长上影线 | 日 K 实体上方明显较长的影线（典型：影线长度 ≥ 实体的 2 倍），常示冲高遇阻 |
| 长下影线 | 日 K 实体下方明显较长的影线，常示探底回升 / 下方有承接 |
| 阳线 / 阴线 | 收盘 > 开盘 为阳线（红），收盘 < 开盘 为阴线（绿） |
| 阳多阴少 | 阳线数量明显多于阴线，强势股常见特征 |
| 十字星 | 开盘价 ≈ 收盘价，实体极小，方向不明示 |

### 7.2 量价 / 分时

| 术语 | 定义 |
|------|------|
| 放量 | 当日成交量 > 近 5 日均量，常以倍数计（如放量 1.5 倍） |
| 缩量 | 当日成交量 < 近 5 日均量，且**量能未萎缩后重新放大**才是延续 |
| 放量滞涨 | 价格上涨但成交量明显放大且**不创新高 / 冲高回落** —— 典型主力出货形态 |
| 缩量回调 | 上涨趋势中，**回调时成交量显著萎缩**，示抛压轻、洗盘干净 |
| 上涨缩量回踩 | 上升趋势中，价格回调至关键支撑位（MA5 / MA10 / 前日收盘等），成交量较上涨段明显萎缩，示抛压轻、洗盘干净 |
| 持续放量上攻 | 上涨过程中成交量温和或明显放大，价格沿分时均线或短期均线上行，盘中未出现大幅冲高回落 |
| 量价齐升 | 价格上涨同时成交量同步放大，且未出现滞涨 |
| 放量冲高回落 | 日内冲高后大幅回落（典型：最高 − 收盘 ≥ 4%），伴随成交量明显放大 |
| 缩量阴跌 | 价格持续下跌且成交量萎缩，无资金回流，不是低吸对象 |
| 冲高回落 | 日内最高价较开盘明显上涨、但收盘价较最高点显著回落（典型：日内最高 − 收盘 ≥ 4%） |
| 分时承接 | 开盘后分时回踩均价线 / 前日收盘价**不破**即被买盘快速拉起 |
| 突破买点 | 放量突破前期高点 / 整理平台（成交量 > 近 5 日均量 1.5 倍） |
| 主力净流入 / 净流出 | 大单（通常单笔 ≥ 50 万或 100 万）净额，正为流入、负为流出 |
| 换手率 | 当日成交量 / 自由流通股本 × 100%，反映交易活跃度 |

### 7.3 板块 / 情绪

| 术语 | 定义 |
|------|------|
| 炸板 | 个股触及涨停后被打开（封板失败），常示买盘力量不足 |
| 炸板率 | 炸板家数 / 总涨停家数 × 100%，**不自拾**作为情绪论据（情绪判定纪律见总纲 §5.1） |
| 连板 | 个股连续多个交易日涨停（2 连板、3 连板 ……） |
| 连板高度 | 当日市场中**最高连板数**，标识题材强度上限 |
| 大面 | 个股当日**大幅下挫**（通常 > 7%），常示亏钱效应强 |
| 大面家数 | 当日跌幅超过阈值的个股数量，**不自拾**作为情绪论据（同上） |
| 涨停破位率 | 已涨停个股中**次日未能延续涨停**的比例，**不自拾**作为情绪论据（同上） |
| 涨停 | 涨幅触及当日涨幅上限（主板 10% / 创业板 20% / 科创板 20%，ST 股 5%）—— **术语本身的板块阈值**，不作为交易判定 |

### 7.4 资金 / 持仓

| 术语 | 定义 |
|------|------|
| 浮盈 / 浮亏 | 当前股价相对持仓成本价的盈亏比例 |
| 时间止损 | 买入后 **N 个交易日内**未出现预期上涨则离场，冲高回落**不**算预期上涨 |
| 加速止盈 | 持仓出现放量滞涨 / 长上影线 / 走势与板块背离 / 资金背离任一信号即倾向落袋（具体信号定义见策略） |
| 移动止损 | 浮盈**达到阈值**后，从最高点回撤固定比例即离场 |
| 利润保护 | 浮盈**达到阈值**后，从最高点回撤固定比例即清仓保利润 |

### 7.5 方向 / 标的

| 术语 | 定义 |
|------|------|
| 活跃方向 | 近期反复活跃、今日资金仍在进攻的热点题材（盘面分析给出的方向名）。**方向本身**用作视野聚焦；**其下个股名单**只是论证该方向的样本，不作选股门槛 |
| 已撤退方向 | 盘面分析指出、本期资金在撤退的方向。**判定以板块归属为准**，名单漏列不代表脱离撤退方向（细分方法见策略） |
| 龙头 | 活跃方向内**辨识度最高、带动性最强**的核心个股（由市场自然形成，**不**依赖 LLM 标记） |
| 套利标的 | 龙头无买点时（涨停 / 高位 / 错过买点），退而求其次的**活跃方向内**中军 / 活跃股。**不**等于冷门跟风股、**不**等于跨方向套利（四要素边界见本文件 §4.3） |
| 同方向 | 持仓股所属板块与某活跃方向**同板块归属** |
| 高位 | 个股当日涨幅处于较高水平（本账号阈值 > 7%，见本文件 §4.3 与策略） |
| 低吸买点 | 攻击方向内强势股的**回踩机会**。**不**等于冷门股抄底，**不**等于尾盘追涨（具体幅度区间 / 时间窗口见策略） |
| 超预期 | 标的在**关键位置**出现超出市场预期的表现（开盘高开 / 分时承接 / 突破关键位） |
| 打板 | 在涨停板上买入（含已封板瞬间追入）。**禁止**（本文件 §4.1） |
| 抄底 | 在下跌趋势（MA5 下行）状态下接"飞刀"。**禁止**（本文件 §4.1） |
| 回踩 | 上涨趋势中价格**回调至前期支撑位**（如均价线、MA5、MA10、前日收盘）后企稳 |
| 题材生命周期 / 题材阶段 | 题材节奏状态机：启动 →〔加强〕→ 分歧 → **分歧转一致** →〔加强〕→ **再分歧 = 退潮预警**。只有两个买入窗口——刚启动时跟风（买不到龙头可跟风）、分歧转一致时买入（优先龙头 / 最强势股）；分歧不必然转一致，一致加强后的再分歧是退潮开始而非新买点（具体阶段判定、买点匹配见策略） |
| 首次爆发（Day 1） | 题材当日首次出现批量涨停或资金大幅流入，属于资金确认阶段 |
| 次日分歧（Day 2） | 首次爆发后次日出现分化，强势股缩量回踩或不破关键位，是低吸窗口 |
| 持续发酵（Day 3+） | 题材已反复活跃多日，此时只参与清晰的健康回踩，仓位收敛 |
| 健康回踩 | 上涨趋势中缩量回踩关键支撑位，且板块/资金未转弱，是低吸前提 |
| 量价健康 | 上涨缩量回踩、持续放量上攻、量价齐升等可持续量价组合；买入 / 持有前必须确认处于量价健康状态（具体判定见策略） |
| 量价衰竭 | 放量滞涨、放量冲高回落、放量下跌、缩量阴跌等不可持续量价组合；出现任一即不可追、持有倾向止盈 |

> **术语采用规则**：本表是通用字典，只收录业内通用术语本身。术语**不**在策略中重复定义，只在策略层引用本表。
