

# 柚子 AI · A 股 AI Agent 项目包

面向 Claude Code / Opencode / Codex 的 A 股 AI 研究项目包：行情查询、AI 盯盘、每日复盘、研究型模拟持仓记录、定时调度一体化 SDK。内置柚子 AI 完整系统指令与五层策略架构（心法纪律 / 流程总纲 / 市场阶段状态机裁决 / 四大战法分册 / 跨战法通用细则，`memory/` 可读可改，调教出最适合你的打法），用自然语言对话即可驱动，也可终端无人值守运行。

## 它能做什么

- **行情查询**：大盘汇总、热点板块、个股详情与分时、连板天梯、主力资金、主题与「今天炒什么」事件、LLM 盘面分析、自然语言选股
- **市场阶段判定**：内置五状态状态机（退潮期 / 冰点期 / 回暖确认期 / 高潮期 / 退潮分歧期），基于收盘情绪温度序列由代码统一判定与转移，盘中自动自愈，当日该用哪套战法不再靠猜
- **AI 盯盘**：盘中自主盯盘、情绪判断、持仓止损止盈检查、按用户自建规则执行模拟交易
- **每日复盘**：盈亏与情绪复盘、操作反思、板块轮动事实记录
- **定时调度**：常驻进程按交易时段自动盯盘、盘后自动复盘，无人值守
- **状态读写**：本地交易日志、自选池、复盘总结、动态策略（纯本地文件）
- **AI 调教**：主动指导 Agent 优化心法和交易策略，调教成最适合自己的样子

## 交易体系一览：节点先手

一句话：**买在情绪转势的节点，卖在情绪高潮的节点——不等确认，也不追涨。**

传统玩法是"等行情确认了再上车"，但 A 股 T+1 之下，等你数完三根阳线确认"主升"，行情往往已近尾声。60 天历史数据回放显示：高潮确认日追入的次日表现明显弱于回暖确认期，也不如大盘温吞时连续强势的板块——追在确认之后，性价比反而更差；而"主升"这个东西，市场层面 60 天里只出现了 3 天，板块层面才是常态（27 段）。所以整套体系的节奏是（**以下均为历史统计规律的研究归纳，样本有限、不预示未来表现，更不构成任何收益承诺**）：

- **市场冰点、跌无可跌时** → 轻仓试探反弹（冰点三通道）
- **情绪回暖的第二天** → 轻仓上车赌连强（确认期先手）
- **某板块连着两天是市场最强** → 日常主菜单：尾盘轻仓低吸它的趋势股，绝不追涨停（板块连强通道，出手主力）
- **情绪高潮、连涨确认** → **不买了**，只持仓、只减仓，随时兑现
- **当天盘面情绪明显恶化** → 什么都别买，休息也是操作

出手时点统一在**尾盘 14:30~14:55**：先手的本质是"用收盘前已定型的信号赌明天"，回放数据口径只保护尾盘买入；当天错过了就次日重新判定，**不追认昨天的信号**。

仓位哲学同样简单：**转势给小仓、验证了加仓、高潮只减仓**——仓位的峰值在确认期，不在高潮日之后。卖出侧三个硬动作：市场阶段转弱当天逢高减仓；持仓板块翻绿或跌出市场前三，48 小时内兑现；个股止损止盈（-5% / 分时四信号 / 3 日不涨）照常，从不过夜。

**这套规则怎么证明不是拍脑袋的？** 每条先手通道都标注数据依据（历史回放验证 / 观察级待验证），每次出手落库标记通道来源，累计 8 次后用 T+2 实际表现审判去留——**规则也要靠实盘数据证明自己，表现不行就下岗**；历史统计不预示未来，体系持续进化而非"找到了圣杯"。完整蓝图、回放数据台账与"禁止的交易"清单见 [`memory/design/2026-09-09-node-first-implementation.md`](./memory/design/2026-09-09-node-first-implementation.md)，细则见 [`memory/strategies/`](./memory/strategies/) 与 [`memory/dynamic-strategy.md`](./memory/dynamic-strategy.md)。

## 快速开始

下载包里的 `.env` 已自动写入专属密钥，开箱即用。两种使用方式任选其一：

**方式 A · AI IDE 对话**

用 Claude Code / Opencode / Codex 打开本项目目录，`.env` 与系统指令自动加载，直接用大白话说需求即可：

```
> 执行一次盯盘

> 你今天为什么会买入「xxx股票」，理由是什么？

> 我需要重构心法和策略，全面的改造为只做接力

> 增加一条纪律：昨日涨停今日禁止买入

> 调整心法策略的候选股，增加热门股列表、近期成交量巨大列表作为候选股

```

**方式 B · 终端无人值守**

```bash
pip install requests   # 安装依赖（SDK 核心请求库）
python watch_scheduler.py
```

常驻进程会在交易日盘中每 5 分钟自动盯盘、每晚 21:00 自动复盘。

> 参数清单、启动选项、日志与排障详见官网：<https://stock.objie.com/skills>

### 手动复制或更换密钥

非下载包（手动复制代码）、或需要更换密钥时：

```bash
cp .env.example .env   # 编辑 .env，把 STOCK_SECRET_KEY 填成你的密钥
```
