

# 柚子 AI · A 股 AI Agent 项目包

面向 Claude Code / Opencode / Codex / Workbuddy / zCode / KimiWork 等多款 AI Agent 工具的 A 股 AI 研究项目包：行情查询、AI 盯盘、每日复盘、研究型模拟持仓记录、定时调度一体化 SDK。内置柚子 AI 完整系统指令与五层策略架构（心法纪律 / 流程总纲 / 市场阶段状态机裁决 / 四大战法分册 / 跨战法通用细则，`memory/` 可读可改，调教出最适合你的打法），用自然语言对话即可驱动，也可终端无人值守运行。

> **仅供学习研究，不构成任何投资建议。** 系统所有数据均来源于互联网整理，会有一定的滞后性和不准确性，据此投资造成的财产损失概不负责。所有「交易」均基于**模拟盘账号**，不涉及真实资金。⚠️⚠️⚠️⚠️⚠️

## 它能做什么

- **行情查询**：大盘汇总、热点板块、个股详情与分时、连板天梯、主力资金、主题与「今天炒什么」事件、LLM 盘面分析、自然语言选股
- **市场阶段判定**：内置五状态状态机（退潮期 / 冰点期 / 回暖确认期 / 高潮期 / 退潮分歧期），基于收盘情绪温度序列由代码统一判定与转移，盘中自动自愈，当日该用哪套战法不再靠猜
- **AI 盯盘**：盘中自主盯盘、情绪判断、持仓止损止盈检查、按用户自建规则执行模拟交易
- **每日复盘**：盈亏与情绪复盘、操作反思、板块轮动事实记录
- **定时调度**：常驻进程按交易时段自动盯盘、盘后自动复盘，无人值守
- **状态读写**：市场阶段状态机、动态策略（纯本地文件）；盯盘 / 复盘总结由调度器自动归档 Markdown 时间线
- **AI 调教**：主动指导 Agent 优化心法和交易策略，调教成最适合自己的样子

## 预置的交易体系一览（短线）

围绕情绪节点组织交易，一轮循环是"冰点 → 升温 → 高潮 → 降温 → 退潮"：**节点不对不买（退潮、高潮全禁），节点对了按窗口轻仓参与，高潮兑现、转弱减仓**（历史统计归纳，样本有限，不预示未来表现，不构成投资建议）。

**买入时点**（先判断今天走到哪一步，再按表操作；当天证据核齐才出手）：

| 走到哪一步 | 盘面什么样 | 什么时候买 | 买什么、注意什么 |
|---|---|---|---|
| **冰点**：昨天刚出现第 1 个冰点日 | 今天回暖了 | 10:00 以后 | 小仓试错，买当天资金一起进攻的板块里还没大涨的股；午后只做低吸 |
| **冰点**：昨天刚出现第 1 个冰点日 | 今天还在冰 | 尾盘 14:30~14:55 | 可以考虑低吸，只买近 10 天至少 3 次进市场前三的主线板块；别抄底 |
| **冰点**：已连冰 2 天以后的日子 | 冰着或回暖都行 | 全天 | 小仓试错；回暖了就买当天资金共振的方向，可以放宽一点仓位；还冰就只买主线板块；没有符合条件的就不出手 |
| **升温**（回暖确认期）：昨天收盘短线情绪站上 55（第 1 天就算，收盘定、次日生效） | 确认回暖 | 早盘 10:00~11:00 或尾盘 14:30~14:55 | 轻仓参与强势板块；午后只做低吸 |
| **高潮**：连涨确认完成 | 涨到高潮 | 仅第 1 天可买（惯性最强日） | 第 1 天照表轻仓参与；**第 2 天起不买**——只持仓、只减仓，随时兑现 |
| **降温**：高潮回落但没崩（退潮分歧期） | 主线还在 | 早盘 10:00~11:30 / 午后 13:00~14:30 | 只做反复活跃主线的回踩低吸（跌幅在 -5%~+3% 之间且企稳）；禁追涨 |
| **退潮**：情绪走弱 | — | 不买 | **没有例外——节点不对，题材再强都不买** |

市场节点一票否决：节点不对，题材再强都不买。节点对了，买入只管三件事：

- **时间点**：按上表窗口执行；板块级机会——某板块连续 2 天市场最热（涨停数居前三）时，升温、冰点节点的尾盘 14:30~14:55 可参与（不追涨停，当天错过不追认）
- **买入对象**：板块内趋势股（站上 5 日线且趋势向上），形态含回踩低吸、分时承接、突破（细则见策略）
- **仓位**：轻仓为主；单只 ≤30%、同板块合计 ≤50%、总量不超过账户仓位上限

**加仓**：首笔试错仓不超过目标仓位的一半，**当日不加仓**；次日起验证成立（板块不退榜、温度不回落，且当日节点许可）才分笔补足；仓位峰值止步于升温期，高潮期与退潮期不加仓。

**卖出**：市场阶段转弱当天逢高减仓；持仓板块翻绿或跌出市场前列，48 小时内分批兑现；个股止损止盈照常执行，从不过夜拖。

**禁开仓**：退潮期节点（无例外）、高潮期第 2 天起、当日情绪保守且资金退潮、交易所监管名单等情形下，禁止一切新开仓。

每条规则标注数据依据（历史回放 / 观察级待验证），出手记录标记通道来源，按实际表现定期审定去留。细则见 [`memory/strategies/`](./memory/strategies/) 与 [`memory/dynamic-strategy.md`](./memory/dynamic-strategy.md)。

## 快速开始

下载包里的 `.env` 已自动写入专属密钥，开箱即用。两种使用方式任选其一：

**方式 A · AI IDE 对话**

用 Claude Code / Opencode / Codex 打开本项目目录，`.env` 与系统指令自动加载，直接用大白话说需求即可。Workbuddy、zCode、KimiWork 等第三方 Agent 工具同样适用：操作方式与 Codex 类似，直接打开整个项目目录（读取 `AGENTS.md`）即可使用：

```
> 执行一次盯盘

> 你今天为什么会买入「xxx股票」，理由是什么？

> 我需要重构心法和策略，全面的改造为只做接力

> 增加一条纪律：昨日涨停今日禁止买入

> 调整心法策略的候选股，增加热门股列表、近期成交量巨大列表作为候选股

```

**方式 B · 终端无人值守**

```bash
pip install requests   # 安装依赖（SDK 核心请求库）
python watch_scheduler.py
```

常驻进程会在交易日盘中每 5 分钟自动盯盘、每晚 21:00 自动复盘。

> 参数清单、启动选项、日志与排障详见官网：<https://stock.objie.com/skills>

### 手动复制或更换密钥

非下载包（手动复制代码）、或需要更换密钥时：

```bash
cp .env.example .env   # 编辑 .env，把 STOCK_SECRET_KEY 填成你的密钥
```

密钥获取见下方「[获取密钥](#获取密钥)」。
