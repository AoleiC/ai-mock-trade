

# 柚子 AI · A 股 AI Agent 项目包

面向 Claude Code / Opencode / Codex 的 A 股 AI 研究项目包：行情查询、AI 盯盘、每日复盘、研究型模拟持仓记录、定时调度一体化 SDK。内置柚子 AI 完整系统指令与五层策略架构（心法纪律 / 流程总纲 / 市场阶段状态机裁决 / 四大战法分册 / 跨战法通用细则，`memory/` 可读可改，调教出最适合你的打法），用自然语言对话即可驱动，也可终端无人值守运行。

> **仅供学习研究，不构成任何投资建议。** 系统所有数据均来源于互联网整理，会有一定的滞后性和不准确性，据此投资造成的财产损失概不负责。所有「交易」均基于**模拟盘账号**，不涉及真实资金。⚠️⚠️⚠️⚠️⚠️

## 它能做什么

- **行情查询**：大盘汇总、热点板块、个股详情与分时、连板天梯、主力资金、主题与「今天炒什么」事件、LLM 盘面分析、自然语言选股
- **市场阶段判定**：内置五状态状态机（防守 / 冰点 / 主升预备 / 主升 / 高位震荡），基于收盘情绪温度序列由代码统一判定与转移，盘中自动自愈，当日该用哪套战法不再靠猜
- **AI 盯盘**：盘中自主盯盘、情绪判断、持仓止损止盈检查、按用户自建规则执行模拟交易
- **每日复盘**：盈亏与情绪复盘、次日计划、自选池整理
- **定时调度**：常驻进程按交易时段自动盯盘、盘后自动复盘，无人值守
- **状态读写**：本地交易日志、自选池、复盘总结、动态策略（纯本地文件）
- **AI 调教**：主动指导 Agent 优化心法和交易策略，调教成最适合自己的样子

## 交易体系一览：节点先手 + 右侧确认

核心哲学：**出手左侧化、阶段判定保持右侧**——在情绪节点（冰位、升温确认期、衰竭拐点）提前拿轻仓先手，不等强势确认后追涨；阶段资格本身仍由收盘温度序列的代码判定，不拿盘中单点情绪猜阶段。

**买入矩阵（按市场阶段）**

| 市场阶段 | 可出手通道 | 定位 |
|----------|-----------|------|
| 冰点（双冰聚簇成型） | 通道 A 冰中博弈 / 通道 A2 拉起博弈 / 通道 B 尾盘认证 | **左侧先手**——冰位当帧出手买逆势强度，不等回升确认 |
| 防守·确认期 / 主升预备 | 通道 C 确认期先手 | **左侧先手**——昨日升温首日的次日（确认期两天）提前轻仓参与，博弈主升放行；确认失败次日离场 |
| 主升 | 全量战法（分歧转一致 / 弱转强 / 缩量回踩企稳） | 分歧转一致是**节点先手**（情绪极值衰竭后的回封），回踩企稳是右侧确认 |
| 高位震荡 | 仅贯穿性主线的回踩买点 | **刻意右侧**——本态即"见顶回落区"，先手买 = 接刀，与止盈方向相反 |
| 其余防守日 | 禁开仓 | **防线**——单日反弹 71% 次日杀回，等一日成为确认期的成本极低 |

**仓位生命周期（建仓 → 加仓 → 减仓 → 清仓）**

1. **建仓（两条路）**：先手路——通道认证即建试错仓（≤ 目标 1/2，单只 ≤15%），买"可能对"；**升级失败（确认失败 / 次日走弱）→ 次日无条件离场，不补不扛**。右侧路——主升 / 震荡态的确认买点（弱转强 / 回踩企稳 / 分歧转一致）直接建标准仓
2. **加仓（必须右侧）**：三条路径——分笔补足（放量突破 / 回踩拉起等强确认出现）/ 冰点试错 T+2 验证成立 / 拐点三步曲确认齐备；**加仓视同新开仓过状态机层**（阶段不放行不加重）；**环境转弱期间禁止一切加重（只减不加）**；天花板：单只 30% / 同方向 50% / 当日仓位上限，三维取最严
3. **减仓（先手到标签，逢高分批不追跌卖）**：① 节点先手——晨起状态机阶段转弱（60 日重放数据支撑）当日分批减仓（首笔 1/3）；盘中温度自近端高点回落 / 主升段见顶回落预警 → 先手止盈半仓（观察级，前向校准）② 环境分层——情绪与资金退潮 / 持仓方向走弱 → 逢高分批减仓，不等个股补跌
4. **清仓（四个硬出口，减仓途中命中立即执行不再等高位）**：持仓方向进入撤退名单 → 红线 0% 清仓；固定止损 -5% / 跌破买入日最低价 / 跌破 10 日线 → 立即卖出；分时四信号（放量滞涨 / 长上影 / 板块背离 / 资金背离）→ 加速止盈清仓或大幅减仓；买入 3 日内未现预期上涨 → 时间止损离场

- 一句话：**先手可以左侧，加重必须右侧；环境转弱只减不加；清仓出口不过夜**

所有先手通道与节点先手减仓均带**观察级统计**（每次出手落库标注通道，累计 8 次后依 T+2 成立率审定去留）——先手假设由前向数据持续验证，不靠拍脑袋。细则见 [`memory/strategies/`](./memory/strategies/) 与 [`memory/dynamic-strategy.md`](./memory/dynamic-strategy.md)。

## 快速开始

下载包里的 `.env` 已自动写入专属密钥，开箱即用。两种使用方式任选其一：

**方式 A · AI IDE 对话**

用 Claude Code / Opencode / Codex 打开本项目目录，`.env` 与系统指令自动加载，直接用大白话说需求即可：

```
> 执行一次盯盘

> 你今天为什么会买入「xxx股票」，理由是什么？

> 我需要重构心法和策略，全面的改造为只做接力

> 增加一条纪律：昨日涨停今日禁止买入

> 调整心法策略的候选股，增加热门股列表、近期成交量巨大列表作为候选股

```

**方式 B · 终端无人值守**

```bash
pip install requests   # 安装依赖（SDK 核心请求库）
python watch_scheduler.py
```

常驻进程会在交易日盘中每 5 分钟自动盯盘、每晚 21:00 自动复盘。

> 参数清单、启动选项、日志与排障详见官网：<https://stock.objie.com/skills>

### 手动复制或更换密钥

非下载包（手动复制代码）、或需要更换密钥时：

```bash
cp .env.example .env   # 编辑 .env，把 STOCK_SECRET_KEY 填成你的密钥
```

密钥获取见下方「[获取密钥](#获取密钥)」。
